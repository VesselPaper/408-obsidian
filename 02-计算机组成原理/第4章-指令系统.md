# 第4章-指令系统

> 指令是CPU能执行的最基本命令。本章讲解CPU如何执行程序，是计算机组成原理的核心内容。

## 4.1 指令格式
#第4章-指令系统/指令格式

### 什么是指令？

```
📌 简单理解：指令就是CPU的"命令"

例子：
- 加法指令：让CPU做加法
- 跳转指令：让CPU跳到某处执行
- 存数指令：把数据存到内存

指令 = 操作码 + 地址码
```

### 指令格式

```
┌────────────────┬────────────────────┐
│   操作码(Opcode)│   地址码(Address)  │
│    若干位      │    若干位          │
└────────────────┴────────────────────┘
```

### 地址码数量

| 类型 | 地址数 | 例子 |
|------|--------|------|
| **零地址** | 0 | 堆栈操作、停机 |
| **一地址** | 1 | 取反、自增 |
| **二地址** | 2 | 加减乘除 |
| **三地址** | 3 | A+B→C |

```
例子（二地址）：
ADD  A, B   →  A = A + B
         ↓      ↓
       目的   源1   源2
```

### 指令字长

```
指令字长 = 指令占的位数

- 半字长：16位
- 单字长：32位  
- 双字长：64位

固定字长 vs 可变字长：
- 固定：简单，但可能浪费空间
- 可变：节省空间，但复杂
```

## 4.2 寻址方式（重点！）
#第4章-指令系统/寻址方式

### 什么是寻址？

```
📌 简单理解：寻址就是找"操作数在哪里"

操作数：CPU要处理的数据
地址：数据在哪里（内存？寄存器？）
```

### 常见寻址方式

| 方式 | 格式 | 说明 | 速度 |
|------|------|------|------|
| **立即寻址** | `MOV R1, #5` | 操作数就在指令中 | 最快 |
| **直接寻址** | `MOV R1, [100]` | 地址在指令中 | 快 |
| **间接寻址** | `MOV R1, [[100]]` | 地址的地址 | 慢 |
| **寄存器寻址** | `MOV R1, R2` | 操作数在寄存器中 | 最快 |
| **寄存器间接** | `MOV R1, [R2]` | 寄存器存地址 | 快 |
| **变址寻址** | `MOV R1, [R2+100]` | 变址+位移 | 中等 |
| **基址寻址** | `MOV R1, [R2+100]` | 基址+位移 | 中等 |
| **相对寻址** | `JMP PC+100` | PC+位移 | 中等 |

```
例子对比：

立即寻址：     ADD R1, #5        → 5就在指令里
直接寻址：     ADD R1, [100]     → 去地址100取数
寄存器寻址：    ADD R1, R2        → R2的值直接用
寄存器间接：    ADD R1, [R2]      → R2存的是地址，去那取数

📌 速度排序（快→慢）：
立即 > 寄存器 > 寄存器间接 > 直接 > 间接
```

### 寻址方式的选择

```
不同寻址方式的用途：

- 立即寻址：常数、初始化
- 寄存器寻址：频繁使用的变量
- 直接寻址：固定地址的变量
- 变址寻址：数组访问 A[i]
- 相对寻址：程序跳转、函数调用
```

## 4.3 CISC vs RISC
#第4章-指令系统/CISC和RISC

### 两种设计理念

```
CISC = Complex Instruction Set Computer
       复杂指令集计算机
       例：x86（Intel/AMD）

RISC = Reduced Instruction Set Computer  
       精简指令集计算机
       例：ARM、MIPS
```

### 对比

| 特性 | CISC | RISC |
|------|------|------|
| **指令数量** | 多（几百条） | 少（几十条） |
| **指令长度** | 不固定 | 固定 |
| **寻址方式** | 多 | 少 |
| **寄存器** | 少 | 多 |
| **执行时间** | 不等长 | 等长 |
| **流水线** | 难实现 | 容易 |
| **代表** | x86 | ARM |

```
RISC的特点：
✓ 指令少而简单
✓ 指令在固定周期完成
✓ 寄存器多（几百个）
✓ 适合流水线
✓ 功耗低 → 手机用ARM

CISC的特点：
✓ 指令复杂，功能强大
✓ 一条指令完成复杂操作
✓ 兼容性好 → PC用x86
```

## 习题4（考研真题精选）

### 选择题

1. **【2011统考真题】** 下列寻址方式中，速度最快的是？
   A. 立即寻址  B. 直接寻址  C. 寄存器寻址  D. 间接寻址  
   > **答案**：A  
   > **解析**：立即寻址操作数就在指令中，不需要访问存储器。

2. **【2013统考真题】** RISC的特点不包括？
   A. 指令条数少  B. 指令长度固定  C. 寻址方式多  D. 大部分指令单周期完成  
   > **答案**：C  
   > **解析**：RISC寻址方式少。

3. **【2015统考真题】** 相对寻址中，转移地址的计算公式是？
   A. PC + 偏移量  B. 基址寄存器 + 偏移量  
   C. 变址寄存器 + 偏移量  D. 指令地址 + 偏移量  
   > **答案**：A  
   > **解析**：相对寻址 = PC + 偏移量。

4. **【2017统考真题】** 某指令系统有200条指令，操作码至少需要多少位？
   A. 6  B. 7  C. 8  D. 9  
   > **答案**：C  
   > **解析**：2⁷=128<200，2⁸=256>200，所以需要8位。

5. **【2019统考真题】** 变址寻址适合用于什么场合？
   A. 程序跳转  B. 访问固定地址  C. 数组访问  D. 堆栈操作  
   > **答案**：C  
   > **解析**：变址寻址适合数组访问，如A[i]。

### 综合应用题

6. **【2012统考真题】** 说明以下寻址方式的特点和适用场景：
   (1) 立即寻址 (2) 直接寻址 (3) 寄存器间接寻址

**参考答案**：
```
(1) 立即寻址：
    特点：操作数直接在指令中
    适用：常数赋值、初始化

(2) 直接寻址：
    特点：操作数地址直接在指令中
    适用：访问固定地址的变量

(3) 寄存器间接寻址：
    特点：寄存器中存地址，去内存取数据
    适用：指针操作、链表遍历
```

7. **【2016统考真题】** 比较CISC和RISC的优缺点。

**参考答案**：
```
CISC优点：
- 指令功能强大，程序代码少
- 兼容性好

CISC缺点：
- 指令复杂，硬件设计难
- 难以流水线

RISC优点：
- 指令简单，硬件设计简单
- 容易流水线，效率高
- 功耗低

RISC缺点：
- 程序代码可能更长
- 需要更多寄存器
```
