## 2.1 进位计数制（基础！）
#第2章-数据的表示和运算/进位计数制

### 什么是进位计数制？

简单说就是"逢几进一"的计数方法：

| 进制 | 基数 | 符号 | 例子 |
|------|------|------|------|
| 十进制 | 10 | 0-9 | 9+1=10 |
| 二进制 | 2 | 0,1 | 1+1=10 |
| 八进制 | 8 | 0-7 | 7+1=10 |
| 十六进制 | 16 | 0-9,A-F | F+1=10 |

```
📌 简单理解：
- 十进制：数到9就进位（0~9，10是进位后的1和0）
- 二进制：数到1就进位（0,1，10是进位后的1和0）
```

### 数制转换（重要！）

#### 二进制 → 十进制（按权展开）

```
例：1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
            = 8 + 0 + 2 + 1 = 11
```

#### 十进制 → 二进制（除2取余）

```
例：11转二进制

11 ÷ 2 = 5 ... 1  ↓
 5 ÷ 2 = 2 ... 1  ↑
 2 ÷ 2 = 1 ... 0  ↑
 1 ÷ 2 = 0 ... 1  ↑
 
结果：1011（从下往上读）
```

#### 二进制 ↔ 八进制/十六进制

```
二进制 → 八进制：3位一组
101 011 → 5 3 → 53

二进制 → 十六进制：4位一组
1010 1100 → A C → AC
```

## 2.2 定点数表示（核心重点！）
#第2章-数据的表示和运算/定点数的表示

### 定点数是什么？

定点数就是**小数点位置固定**的数。一般有两种形式：

```
定点整数：小数点固定在最低位右边
  [符号位][数值位...]  →  如 00011 表示 +3

定点小数：小数点固定在符号位后面
  [符号位][.数值位...]  →  如 0.101 表示 0.625
```

### 原码、反码、补码（必考！）

**为什么需要三种表示？**

```
📌 简单理解：
- 原码：最直观的表示，但计算不方便（0-1=-1？不对！）
- 反码：过度产物，现在很少直接用
- 补码：计算最方便，硬件实现简单（核心：把减法变加法）
```

| 表示方法 | 正数 | 负数 | 8位整数表示 +3 | 8位整数表示 -3 |
|----------|------|------|-----------------|-----------------|
| **原码** | 一样 | 符号位1 | 00000011 | 10000011 |
| **反码** | 一样 | 符号位1+数值位取反 | 00000011 | 11111100 |
| **补码** | 一样 | 反码+1 | 00000011 | 11111101 |
| **移码** | 补码符号位取反 | - | 10000011 | 01111101 |

```
补码的精髓：-3 = +3 的补码是 11111101
验证：3 + (-3) = 00000011 + 11111101 = 1 00000000 → 溢出位丢弃 = 0 ✓
```

> 📌 **考研核心规则**：
> 1. **整数用补码表示**，范围是 -2ⁿ⁻¹ ~ 2ⁿ⁻¹ - 1
> 2. **补码运算时**，符号位一起参与运算
> 3. **溢出判断**：最高位进位 ⊕ 次高位进位 = 1 时溢出

### 定点数运算

#### 补码加减法（最重要！）

```c
// 补码加法
[A]补 + [B]补 = [A+B]补（模2ⁿ运算，丢弃溢出位）

// 补码减法  
[A-B]补 = [A]补 + [-B]补
其中 [-B]补 = [B]补 连同符号位取反加1
```

#### 原码乘除法

```
原码乘法：符号位异或，数值位绝对值相乘
  例：(-3) × 2 = -6
      符号：1⊕0=1，数值：3×2=6 → 结果：10000110
```

## 2.3 浮点数表示（重要！）
#第2章-数据的表示和运算/浮点数的表示

### 浮点数是什么？

浮点数就是**小数点位置不固定**的数，科学计数法：

```
浮点数格式：N = M × Rᵉ
  M：尾数（决定精度）
  R：基数（通常为2）
  e：阶码（决定范围）
  
例：3.14 = 0.314 × 10¹
```

### IEEE 754标准（考研必考！）

```
32位单精度浮点数：
┌────────────────┬──────────────┬─────────────────────────┐
│  符号位(1位)   │  阶码(8位)   │    尾数(23位)           │
│      S         │     E        │          M              │
└────────────────┴──────────────┴─────────────────────────┘

格式：(-1)^S × 1.M × 2^(E-127)
  - 规格化：尾数隐含1（即实际尾数是1.M）
  - 非规格化：表示很小的数
  
特殊值：
  - E=255, M=0 → 无穷大
  - E=255, M≠0 → NaN(非数)
  - E=0 → 非规格化数
```

| 类型 | 符号位 | 阶码 | 尾数 | 值 |
|------|--------|------|------|-----|
| 规格化 | S | 1~254 | 任意 | (-1)^S × 1.M × 2^(E-127) |
| 非规格化 | S | 0 | 非0 | (-1)^S × 0.M × 2^(-126) |
| 零 | S | 0 | 0 | 0 |
| 无穷大 | S | 255 | 0 | (-1)^S × ∞ |

### 浮点数运算步骤

```
浮点数加减法（5步）：

1. 对阶：小阶向大阶看齐，尾数右移
   例：0.5×2⁰ + 0.25×2¹ 
     → 0.5×2⁰ + 0.5×2⁰（对齐！）

2. 尾数加减：按对齐后的阶码相加减

3. 规格化：尾数归一化（变成1.xxxx形式）
   - 结果尾数绝对值 ≥ 1 → 右移，阶码+1
   - 结果尾数绝对值 < 0.5 → 左移，阶码-1

4. 舍入：处理尾数右移丢失的位
   - 0舍1入（类似四舍五入）
   - 恒置1法

5. 判溢出：阶码是否超出范围
   - 阶码上溢 → 无穷大
   - 阶码下溢 → 0
```

> 📌 **考研易错点**：浮点数比较不能用等号，要用精度范围！

## 2.4 算术逻辑单元（ALU）
#第2章-数据的表示和运算/ALU

### ALU是什么？

ALU（Arithmetic and Logic Unit）是CPU中**执行算术和逻辑运算**的部件：

```
CPU内部结构：
┌─────────────────────────────────┐
│              ALU               │ ← 运算核心
│  ┌─────────┐ ┌─────────────┐  │
│  │ 加法器  │ │ 逻辑运算单元│  │
│  │  ＋－×÷ │ │   AND/OR/NOT│  │
│  └─────────┘ └─────────────┘  │
├─────────────────────────────────┤
│            寄存器组             │ ← 临时存储
└─────────────────────────────────┘
```

### 加法器电路

| 类型 | 说明 | 特点 |
|------|------|------|
| **半加器** | 只考虑两个1位相加 | 不考虑进位输入 |
| **全加器** | 考虑进位输入 | 三输入求和 |
| **并行加法器** | 多个全加器并行 | 快速加法 |
| **超前进位加法器** | 提前计算进位 | 最快的加法器 |

```
全加器公式：
和 S = A ⊕ B ⊕ C_in
进位 C_out = (A ∧ B) ∨ (C_in ∧ (A ⊕ B))
```

## 习题2（考研真题精选）

### 选择题

1. **【2011统考真题】** 8位补码能表示的整数范围是？
   A. -128~127  B. -127~128  C. -129~128  D. -128~128  
   > **答案**：A  
   > **解析**：8位补码范围是 -2⁷ ~ 2⁷-1 = -128 ~ 127

2. **【2013统考真题】** 浮点数的IEEE754表示中，阶码采用什么编码？
   A. 原码  B. 补码  C. 移码  D. 反码  
   > **答案**：C  
   > **解析**：IEEE754使用偏置码（类似移码），偏置量为127

3. **【2015统考真题】** 下列关于补码的说法，正确的是？
   A. 补码的0只有一种表示  
   B. 补码的符号位参与运算  
   C. 补码可以直接比较大小  
   D. 补码减法可以用加法实现  
   > **答案**：A、B、D  
   > **解析**：补码0只有一种表示（00000000），符号位参与运算，减法变加法。

4. **【2017统考真题】** IEEE754单精度浮点数中，阶码为10000010，尾数为100100...0，求表示的数值。

**参考答案**：
```
阶码E = 10000010₂ = 130
尾数M = 1.100100...0（隐含1）
数值 = (-1)^0 × 1.1001 × 2^(130-127)
     = 1.5625 × 2³ = 1.5625 × 8 = 12.5
```

### 计算题

5. **【2016统考真题】** 假设补码表示的8位整数x=11111101，y=00000010，计算x+y，并说明是否溢出。

**参考答案**：
```
x = 11111101 → -3（补码）
y = 00000010 → 2
x + y = 11111101 + 00000010 = 11111111 → -1（补码）

判断溢出：
  最高位进位 C7 = 1（产生进位）
  次高位进位 C6 = 1（产生进位）
  C7 ⊕ C6 = 0 → 无溢出 ✓

结果：-1，无溢出
```

6. **【2019统考真题】** 将十进制-0.625表示为IEEE754单精度浮点数。

**参考答案**：
```
-0.625 = -5/8 = -0.101₂ = -1.01 × 2⁻¹

符号位 S = 1
阶码 E = -1 + 127 = 126 = 01111110
尾数 M = .01（后面补0）→ 010000...0

结果：1 01111110 01000000000000000000000
```
