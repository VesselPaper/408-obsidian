# 第3章-存储器层次结构

> 存储器是计算机的"记忆系统"，本章讲解如何让计算机"记得更多、更快"。考研重点章节！

## 3.1 存储器的分类
#第3章-存储器层次结构/存储器的分类

### 存储器的层次结构

```
存储器的层次结构：

| 层次 | 名称 | 速度 | 说明 |
|------|------|------|------|
| L0 | 寄存器 | 最快，几个纳秒 | CPU内部 |
| L1 | Cache | 很快，几纳秒 | CPU和内存之间 |
| L2 | 内存 | 中等，几十纳秒 | 主板上 |
| L3 | 固态硬盘 | 较慢，微秒级 | 硬盘 |
| L4 | 机械硬盘 | 最慢，毫秒级 | 硬盘 |

容量排序（大→小）：
机械硬盘 > 固态硬盘 > 内存 > Cache > 寄存器
```

### 按存储介质分类

| 介质 | 例子 | 特点 |
|------|------|------|
| **半导体** | RAM、ROM | 速度最快 |
| **磁表面** | 硬盘、磁带 | 容量大，便宜 |
| **光存储** | CD、DVD | 只读，容量大 |

### 按存取方式分类

| 方式 | 说明 | 例子 |
|------|------|------|
| **随机存取** | 想读哪个地址就读哪个 | 内存 |
| **顺序存取** | 只能从头开始一个个找 | 磁带 |
| **直接存取** | 先定位再顺序找 | 硬盘 |

## 3.2 主存储器（内存）
#第3章-存储器层次结构/主存储器

### RAM vs ROM

```
📌 简单理解：
- RAM = 随机存取存储器 = 可以读也可以写 = 内存条
- ROM = 只读存储器 = 只能读不能写 = 固态的

RAM（易失性，断电丢失）：
- SRAM：静态RAM，用触发器，速度快，Cache用
- DRAM：动态RAM，用电容，速度慢，内存条用
  → 需要"刷新"（定期充电）

ROM（非易失，断电保持）：
- PROM：可编程一次
- EPROM：可擦除重写
- EEPROM：电可擦除
- Flash：U盘用的那种
```

### DRAM的刷新

```
📌 为什么要刷新？
DRAM用电容存储数据，电容会漏电
→ 需要定期"充电"刷新

刷新方式：

1. 集中刷新：
   ┌──────────────┬──────────────┬──────────────┐
   │  正常工作    │ 集中刷新(停止工作)│  正常工作   │
   └──────────────┴──────────────┴──────────────┘

2. 分散刷新：
   ┌──────┬──────┬──────┬──────┐
   │读/写 │ 刷新 │读/写 │ 刷新 │...
   └──────┴──────┴──────┴──────┘

3. 异步刷新：
   每行定时刷新，不集中在某一时刻
```

## 3.3 Cache（高速缓存）- 重点！
#第3章-存储器层次结构/Cache

### 为什么需要Cache？

```
📌 简单理解：Cache就是"缓存"

例子：
- 你去图书馆借书
- 如果每次都去书架找，很慢
- 但如果在桌上放几本常用的，就会快很多

Cache就是内存放在CPU桌上的"常用书"

原理：程序的局部性
- 时间局部性：一会用到的数据很可能再次用到
- 空间局部性：用到的数据附近的数据也可能会用
```

### Cache的映射方式

```
📌 核心问题：主存的块放到Cache的哪里？

1. 直接映射（最简单）
   主存块号 % Cache行数 = Cache行号
   
   例子：Cache有8行，主存第0、8、16...块都只能放第0行
   优点：查找快
   缺点：容易冲突

2. 全相联映射（最灵活）
   主存块可以放到任意Cache行
   
   例子：Cache有8行，主存任意块可以放任意行
   优点：命中率高
   缺点：查找慢（要比较所有行）

3. 组相联映射（折中）
   Cache分组，组内全相联，组间直接映射
   
   例子：4组×2路，Cache共8行
   → 常用方案！
```

### Cache的替换策略

```
当Cache满了，需要替换时选哪个？

1. 随机替换：随便选一个
2. FIFO：选最早进来的（可能换掉常用的）
3. LRU：选最近最少使用的 ✓ 推荐
   → 命中率最高
```

### Cache的写策略

```
📌 核心问题：Cache和内存的数据不一致

1. 写直达（Write Through）：
   写Cache时同时写内存
   → 简单，保证一致，但慢
   
2. 写回（Write Back）：
   写Cache时不写内存，替换时才写
   → 快，但可能不一致

考研常用：写回法
```

## 3.4 虚拟存储器
#第3章-存储器层次结构/虚拟存储器

### 什么是虚拟存储器？

```
📌 简单理解：虚拟存储 = "画饼充饥"

你的电脑实际内存：8GB
但你总共开了20GB的程序
→ 操作系统把不用的放到硬盘
→ 用的部分放到内存
→ 看起来像有20GB内存

原理：主存+辅存 = 虚拟内存
```

### 虚拟存储器的方式

| 方式 | 说明 | 例子 |
|------|------|------|
| **页式** | 按固定大小分页 | 4KB一页 |
| **段式** | 按程序逻辑分段 | 代码段、数据段 |
| **段页式** | 先分段再分页 | 结合两者优点 |

### 页面置换算法

```
当内存满了，需要换出页面时选哪个？

1. OPT（最佳）：选以后最长时间不用的
   → 理论最优，但无法实现（需要知道未来）
   
2. FIFO：选最早进来的
   → 简单，但可能换掉常用的（Belady异常）
   
3. LRU：选最近最少使用的 ✓ 
   → 实际最常用，命中率接近OPT
   
4. 时钟（Clock）：改进的LRU
   → 用"使用位"标记，简单高效
```

## 习题3（考研真题精选）

### 选择题

1. **【2011统考真题】** 下列存储器中，属于易失性存储器的是？
   A. SRAM  B. PROM  C. ROM  D. Flash  
   > **答案**：A  
   > **解析**：SRAM是易失性的，断电丢失；PROM/ROM/Flash是非易失的。

2. **【2013统考真题】** Cache的映射方式中，命中率最高的是？
   A. 直接映射  B. 全相联映射  C. 组相联映射  D. 一样  
   > **答案**：B  
   > **解析**：全相联映射最灵活，命中率最高。

3. **【2015统考真题】** 虚拟存储器的作用是？
   A. 提高存取速度  B. 扩大寻址空间  
   C. 提高存储容量  D. 降低功耗  
   > **答案**：B  
   > **解析**：虚拟存储器让用户可以使用比实际内存更大的地址空间。

4. **【2017统考真题】** 下列关于Cache的说法，正确的是？
   A. Cache在CPU外部  B. Cache越大越好  
   C. 采用写回策略时，内存和Cache可能不一致  C. Cache不需要刷新  
   > **答案**：C  
   > **解析**：写回策略可能导致不一致。

5. **【2019统考真题】** 页面置换算法中，可能发生Belady异常的是？
   A. FIFO  B. LRU  C. OPT  D. 时钟  
   > **答案**：A  
   > **解析**：FIFO可能发生Belady异常（增加物理页面反而增加缺页率）。

### 计算题

6. **【2014统考真题】** 假设Cache采用直接映射，Cache容量为16KB，块大小为16B，主存容量为1MB。求：
   (1) Cache有多少行？
   (2) 主存地址多少位？
   (3) 主存块号有多少位？

**参考答案**：
```
(1) Cache行数 = 16KB / 16B = 1024行
(2) 主存容量1MB = 2^20，所以主存地址20位
(3) 主存块数 = 1MB / 16B = 2^16块
    主存块号 = log₂(2^16) = 16位
```

7. **【2016统考真题】** 某系统采用LRU页面置换算法，进程共有4个页面，页面引用序列：1,2,3,4,1,2,5,1,2,3,4,5。求缺页次数（开始时4个页面都不在内存）。

**参考答案**：
```
初始：空
1,2,3,4 → 4次缺页（装入4页）
1,2 → 在内存，不缺页
5 → 缺页（需要换出）
  LRU换出1（最近最少用）
  装入5 → 1次缺页
1 → 缺页，换出2，装入1 → 1次缺页
2 → 缺页，换出3，装入2 → 1次缺页  
3,4,5 → 都不缺页

总缺页次数：4+1+1+1=7次
```
