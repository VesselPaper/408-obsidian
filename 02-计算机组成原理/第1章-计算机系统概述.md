> 本章是计算机组成原理的入门篇，帮助理解计算机的整体架构和基本工作原理。

## 1.1 计算机是什么？
#第1章-计算机系统概述/计算机的基本组成

**计算机系统**由**硬件**和**软件**两大部分组成。

```
┌────────────────────────────────────────┐
│            计算机系统                  │
├──────────────────┬─────────────────────┤
│    硬件系统       │     软件系统        │
│  ┌────────────┐  │  ┌──────────────┐  │
│  │  CPU       │  │  │  操作系统    │  │
│  │  内存      │  │  │  编译程序    │  │
│  │  硬盘      │  │  │  数据库      │  │
│  │  显示器... │  │  │  你的微信... │  │
│  └────────────┘  │  └──────────────┘  │
└──────────────────┴─────────────────────┘
```

### 冯·诺依曼体系结构（重要！）

现代计算机的基础结构，由**存储程序**原理决定：

```
        ┌──────────────┐
        │   控制器     │ ← 指挥中心
        └──────┬───────┘
               │
        ┌──────▼───────┐    数据流动
        │   运算器     │ ← 计算中心
        └──────┬───────┘
               │
  ┌────────────┼────────────┐
  │            │            │
┌─▼────┐  ┌────▼────┐  ┌───▼────┐
│存储器 │  │输入设备│  │输出设备│
│ 内存  │  │ 键盘/鼠标│ │显示器 │
└──────┘  └─────────┘  └───────┘

核心特点：
1. 计算机由五大部件组成
2. 采用二进制表示数据
3. 存储程序：程序和数据都存在内存中
```

### 硬件系统五大部件

| 部件 | 功能 | 举例 |
|------|------|------|
| **运算器** | 执行算术运算和逻辑运算 | ALU算术逻辑单元 |
| **控制器** | 协调各部件工作，取指令执行指令 | CPU控制单元 |
| **存储器** | 存放程序和数据 | 内存、硬盘 |
| **输入设备** | 给计算机输入信息 | 键盘、鼠标、扫描仪 |
| **输出设备** | 输出计算机处理结果 | 显示器、打印机 |

### 软件系统

| 软件类型 | 说明 | 例子 |
|----------|------|------|
| **系统软件** | 操作系统，管理硬件 | Windows、Linux |
| **应用软件** | 用户使用的程序 | 微信、游戏、Word |

## 1.2 计算机的层次结构
#第1章-计算机系统概述/计算机的层次结构

计算机通过多层抽象，每层使用下层提供的服务：

```
┌─────────────────────────────────────────────────┐
│  高级语言级   (你写的 C/Java/Python 代码)       │
├─────────────────────────────────────────────────┤
│  汇编语言级   (汇编代码)                        │
├─────────────────────────────────────────────────┤
│  操作系统级   (Linux/Windows 系统调用)          │
├─────────────────────────────────────────────────┤
│  机器级       (CPU能看懂的二进制指令)           │  ← 机器语言
├─────────────────────────────────────────────────┤
│  微程序级     (硬件直接执行的微指令)            │  ← 微程序
└─────────────────────────────────────────────────┘

📌 简单理解：
- 越往上越"人类友好"，越往下越"机器友好"
- 每层都需要"翻译"成下一层能理解的形式
```

## 1.3 计算机性能指标（考研重点！）
#第1章-计算机系统概述/计算机的性能指标

### 核心指标

| 指标 | 含义 | 说明 |
|------|------|------|
| **主频** | CPU时钟频率，单位Hz | 2.8GHz表示每秒28亿个时钟周期 |
| **CPI** | 每条指令需要的时钟周期数 | CPI越小，CPU越快 |
| **MIPS** | 每秒执行百万条指令数 | 主频÷CPI×10⁶ |
| **MFLOPS** | 每秒执行百万次浮点运算 | 衡量浮点运算能力 |
| **吞吐量** | 单位时间完成的任务数 | 系统整体性能 |
| **响应时间** | 从提交到完成的时间 | 用户感知 |

### 重要公式！

**指令执行时间**：
```
一条指令的执行时间 = CPI × 时钟周期 = CPI / 主频
```

**MIPS计算**：
```
MIPS = 主频 / CPI / 10⁶
    = 1 / (CPI × 时钟周期) × 10⁶
```

**系统性能**：
```
系统性能 = 1 / 响应时间
系统吞吐量 = 单位时间处理任务数
```

> 📌 **考研计算题常见**：已知主频和CPI，求MIPS或指令执行时间

### 例子

```
题目：某计算机主频为1GHz，平均CPI为3，求MIPS和指令执行时间
解：
  MIPS = 1×10⁹ / 3 / 10⁶ = 333.33
  一条指令时间 = 3 / 1×10⁹ = 3ns
```

## 习题1（考研真题精选）

### 选择题

1. **【2012统考真题】** 下列选项中，描述正确的是？
   A. 控制器能直接访问计算机的存储器  
   B. 运算器负责算术运算，控制器负责逻辑运算  
   C. 运算器和控制器合在一起就是CPU  
   D. 存储器可直接与CPU交换数据  
   > **答案**：C  
   > **解析**：CPU = 运算器 + 控制器。存储器通过数据总线与CPU交换数据，不能"直接"访问。

2. **【2014统考真题】** 计算机系统中，以下说法正确的是？
   A. 主频高的CPU一定比主频低的快  
   B. 吞吐率表示单位时间内处理的任务数  
   C. CPI表示每条指令的时钟周期数  
   D. MIPS = 主频 / CPI / 10⁶  
   > **答案**：B、C、D  
   > **解析**：A错误，主频高不一定快，还要看CPI。

3. **【2016统考真题】** 冯·诺依曼结构的特点不包括？
   A. 采用二进制  B. 存储程序  C. 五大部件  D. 分布计算  
   > **答案**：D  
   > **解析**：冯·诺依曼结构的核心是集中式计算，非分布式。

4. **【2018统考真题】** 某计算机主频为2GHz，程序包含10⁶条指令，每条指令平均5个时钟周期，则程序执行时间为？
   A. 5ms  B. 10ms  C. 5μs  D. 10μs  
   > **答案**：B  
   > **解析**：执行时间 = 10⁶ × 5 / 2×10⁹ = 2.5×10⁻³s = 2.5ms  
   > 注意单位换算！

### 计算题

5. **【2013统考真题】** 某计算机指令集中共有11种操作，已知程序中有10000条指令，平均每条指令有2个操作数。假设每个操作数的寻址方式有3种，请设计该指令格式，并计算该计算机的存储字长至少为多少位？

**参考解答**：
- 11种操作需要 log₂11 ≈ 4位（2⁴=16 > 11）
- 2个操作数，每个需要3种寻址方式，log₂3 ≈ 2位
- 指令格式：4位操作码 + 2×2位寻址方式 + 操作数字段
- 存储字长至少需要能存下一个操作数 + 指令格式

6. **【2015统考真题】** 已知某程序有100000条指令，平均CPI为4，主频为400MHz。求：
   (1) 执行该程序需要的时间
   (2) 如果CPI降低到2.5，执行时间减少多少？

**参考答案**：
```
(1) 执行时间 = 指令数 × CPI × 时钟周期
             = 100000 × 4 / 400×10⁶
             = 1×10⁵ × 1×10⁻⁸ = 1ms
             
(2) 新执行时间 = 100000 × 2.5 / 400×10⁶ = 0.625ms
    减少时间 = 1 - 0.375 = 0.375ms
    性能提升 = 1 / 0.625 ÷ 1 / 1 = 1.6倍
```
