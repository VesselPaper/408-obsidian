# 第3章 处理机调度

> 处理机调度就是决定"让谁先用CPU"的问题。本章讲解各种调度算法，是操作系统的核心考点！

## 3.1 调度的基本概念
#第3章-处理机调度/调度层次

### 什么是处理机调度？

```
📌 简单理解：调度就是"排班"

例子：一个小餐厅只有1个厨师
- 来了3个客人点菜
- 厨师先给谁做？
- 这就是"调度"问题
```

### 调度的三个层次

```
三层调度对比：

| 层级 | 名称 | 说明 | 频率 |
|------|------|------|------|
| 高级 | 作业调度 | 从外存后备队列选作业调入内存 | 几分钟~几十分钟一次 |
| 中级 | 内存调度 | 把进程挂起或激活，平衡内存 | 几秒~几分钟一次 |
| 低级 | 进程调度 | 从内存就绪队列选进程分配CPU | 几毫秒一次（最频繁） |

简单记忆：
高级：谁进内存
中级：谁休息
低级：谁用CPU
```

### 调度算法的目标

```
不同系统的侧重点：

| 系统类型 | 侧重点 |
|----------|---------|
| 批处理系统 | 提高吞吐量、缩短周转时间、提高CPU利用率 |
| 分时系统 | 响应时间快、公平性 |
| 实时系统 | 截止时间保证、可预测性 |

📌 共同目标：公平、资源利用率高、响应快、吞吐量大
```

## 3.2 调度算法（重点！）
#第3章-处理机调度/调度算法

### 3.2.1 先来先服务（FCFS）

```
📌 简单理解：排队，谁先来谁先办

示例：三个进程到达时间都是0
进程A：运行时间3
进程B：运行时间1
进程C：运行时间2

调度顺序：A → B → C
甘特图：
A: |███|      │
B:        |█|    │
C:            |██|
时间: 0  1  2  3  4  5  6

特点：
✓ 简单公平
✗ 长作业等太久
```

### 3.2.2 短作业优先（SJF/SPF）

```
📌 简单理解：谁用时短谁先办

示例：
进程A：运行时间6，到达时间0
进程B：运行时间3，到达时间2
进程C：运行时间4，到达时间4

调度：
时刻0：A到达 → 选A
时刻2：B到达，但A正在运行
时刻6：A结束，此时B,C都到了 → 选B（时间短）
时刻9：B结束 → 选C

调度顺序：A → B → C
周转时间：A=6, B=7(9-2), C=5(9-4)
平均周转时间 = (6+7+5)/3 = 6

特点：
✓ 平均周转时间最短
✗ 长作业可能"饿死"
✗ 需要知道运行时间
```

### 3.2.3 优先级调度

```
📌 简单理解： VIP优先

优先级类型：
- 静态优先级：创建时确定，不变
- 动态优先级：运行时可以变

示例：
进程A：优先级5，运行时间3
进程B：优先级3，运行时间1
进程C：优先级4，运行时间2

调度顺序：先A(CPU) → B → C
```

### 3.2.4 时间片轮转（RR）

```
📌 简单理解：大家轮流来，每人用一会

示例：时间片=2
进程A：运行时间4
进程B：运行时间3
进程C：运行时间2

执行顺序：
0-2: A
2-4: B
4-5: C(A,B完成，C时间片2不够，只用1)
5-7: A(A还有时间)
7-9: C

特点：
✓ 公平
✓ 响应快
✗ 上下文切换开销大
```

> 📌 **考研重点**：时间片轮转是分时系统的标准算法！

### 3.2.5 多级反馈队列（综合最优！）

```
多级反馈队列结构：

| 队列 | 优先级 | 时间片 |
|------|--------|--------|
| 第1级 | 最高 | 2 |
| 第2级 | 中等 | 4 |
| 第3级 | 最低 | 8 |

规则：
1. 新进程进入第1级队列
2. 如果时间片用完还没完成，降入下一级
3. 如果上级队列有进程，下级先等着
4. 各级队列内部用FCFS

优点：
✓ 短作业优先（第1级）
✓ 长作业不会饿死（最终会轮到）
✓ I/O型进程优先（经常阻塞升到高级）
```

## 3.3 调度算法对比
#第3章-处理机调度/算法对比

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **FCFS** | 简单公平 | 对短作业不友好 | 批处理 |
| **SJF** | 平均周转时间最短 | 长作业饿死 | 批处理 |
| **优先级** | 可以区分紧急程度 | 低优先级饿死 | 所有系统 |
| **RR** | 公平响应快 | 开销大 | 分时系统 |
| **多级反馈** | 综合最优 | 复杂 | 通用 |

## 3.4 实时调度（了解）
#第3章-处理机调度/实时调度

### 实时系统特点

```
📌 简单理解：必须在"截止时间"前完成！

例子：
- 飞机自动驾驶：必须在X秒内响应
- 工业控制：必须在X毫秒内动作

实时系统分类：
- 硬实时：必须完成（飞机控制）
- 软实时：尽量完成（视频播放）
```

### 实时调度算法

| 算法 | 原理 |
|------|------|
| **EDF** | 谁截止时间早谁先做 |
| **LLF** | 谁最"着急"谁先做 |

## 习题3（考研真题精选）

### 选择题

1. **【2011统考真题】** 在操作系统中，"调度"指什么？
   A. 从磁盘选择进程调入内存  
   B. 从内存选择进程使用CPU  
   C. 从外存选择作业调入内存  
   D. 从CPU选择进程使用内存  
   > **答案**：B  
   > **解析**：进程调度是从就绪队列选进程分配CPU。

2. **【2013统考真题】** 下列选项中，满足短作业优先且不会发生饥饿的是？
   A. FCFS  B. SJF  C. RR  D. 多级反馈队列  
   > **答案**：D  
   > **解析**：多级反馈队列综合了SJF的优点，同时避免长作业饿死。

3. **【2015统考真题】** 某系统采用基于优先级的调度，优先级相同则用时间片轮转，该系统属于什么系统？
   A. 批处理  B. 实时  C. 分时  D. 都不是  
   > **答案**：C  
   > **解析**：时间片轮转是分时系统的特征。

4. **【2017统考真题】** 下列关于FCFS和SJF的说法，正确的是？
   A. FCFS平均周转时间短  
   B. SJF对长作业友好  
   C. FCFS对短作业不友好  
   D. SJF需要知道作业运行时间  
   > **答案**：C、D  
   > **解析**：SJF平均周转时间最短，需要预知运行时间。

5. **【2019统考真题】** 时间片轮转调度中，时间片大小为2，第1个进程运行完需要几个时间片？
   A. 1  B. 2  C. 3  D. 4  
   > **答案**：C  
   > **解析**：运行时间4，时间片2，需要2个时间片。

### 计算题

6. **【2012统考真题】** 假设3个进程到达时间分别为0、1、3，运行时间分别为8、4、5。用SJF和FCFS分别计算平均周转时间。

**参考答案**：
```
FCFS：运行顺序A→B→C
- A: 周转时间 = 8-0 = 8
- B: 周转时间 = 12-1 = 11  
- C: 周转时间 = 17-3 = 14
平均周转时间 = (8+11+14)/3 = 11

SJF：
- 0时刻A到，运行A(8)
- 1时刻B到，但A在运行
- 3时刻C到
- 8时刻A结束，选B(C=3<4)，运行B(4)
- 12时刻B结束，运行C(5)
- 17时刻C结束
- A: 8-0 = 8
- B: 12-1 = 11
- C: 17-3 = 14
平均周转时间 = 11（相同）
```

7. **【2016统考真题】** 简述多级反馈队列调度算法的工作原理。

**参考答案**：
```
1. 设置多个就绪队列，优先级从高到低
2. 每个队列时间片大小不同（递增）
3. 新进程先进入第1级队列
4. 如果时间片用完未完成，降入下一级
5. 高级队列为空时才调度低级队列
6. 优点：综合了FCFS、SJF、RR的优点
```

> **本章小结**
> 1. 调度层次：高级→中级→低级
> 2. FCFS：简单公平，对短作业不友好
> 3. SJF：平均周转时间最短，可能长作业饿死
> 4. 时间片轮转：分时系统标准，公平响应快
> 5. 多级反馈队列：综合最优的调度算法
