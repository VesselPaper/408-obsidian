# 第9章 磁盘存储器管理

## 9.1 外存的组织方式
### 9.1.1 连续组织方式
**连续组织方式**是指将文件的数据连续存储在磁盘的连续块中。

**优点**：
- 访问速度快（顺序访问）
- 实现简单

**缺点**：
- 容易产生外部碎片
- 文件大小固定，不易扩展
- 文件删除后，空间回收困难

**适用场景**：
- 固定大小的文件
- 顺序访问的文件

### 9.1.2 链接组织方式
**链接组织方式**是指将文件的数据存储在磁盘的不连续块中，通过指针链接。

**类型**：
- **隐式链接**：文件的每个块中包含指向下一个块的指针
- **显式链接**：使用一个链接表记录文件的块分配情况

**优点**：
- 没有外部碎片
- 文件大小可以动态扩展
- 空间利用率高

**缺点**：
- 随机访问效率低
- 指针占用额外空间
- 可靠性较低（指针损坏会导致文件丢失）

### 9.1.3 索引组织方式
**索引组织方式**是指使用索引表记录文件的块分配情况。

**优点**：
- 随机访问效率高
- 文件大小可以动态扩展
- 空间利用率高

**缺点**：
- 需要额外的索引空间
- 索引表的维护开销

**实现方式**：
- 单级索引
- 多级索引
- 混合索引（如Unix的inode）

## 9.2 文件存储空间的管理
### 9.2.1 空闲区表法和空闲链表法
**空闲区表法**：使用一个表记录所有空闲区的起始位置和大小。

**空闲链表法**：将空闲区链接成一个链表。

**类型**：
- **空闲块链表**：将每个空闲块链接成链表
- **空闲区链表**：将每个空闲区链接成链表

**优点**：
- 实现简单
- 空间分配效率较高

**缺点**：
- 空闲区表法需要额外的表空间
- 空闲链表法的遍历开销较大

### 9.2.2 位示图法 ⭐

**原理**：用一个二进制位表示一个磁盘块的使用情况（0=空闲，1=已使用）。

**计算示例**：
> 设位图有8个字，每字32位。块号从1开始编号。
> 块号100 → (100-1)/32 = 3余3 → 字号=4，位号=4（从1计数）

> [!tip] 位示图计算
> 字号 = (块号-1) / 字长 + 1
> 位号 = (块号-1) % 字长 + 1

### 9.2.3 成组链接法
**成组链接法**是指将空闲块分成若干组，每组的块数和下一组的位置记录在当前组的最后一个块中。

**优点**：
- 空间利用率高
- 分配和回收操作高效
- 适用于大磁盘

**缺点**：
- 实现复杂
- 组的大小需要合理设置

## 9.3 提高磁盘I/O速度的途径
### 9.3.1 磁盘高速缓存
**磁盘高速缓存**是指在内存中设置的临时存储区域，用于存储磁盘的最近访问数据。

**目的**：
- 减少磁盘I/O次数
- 提高I/O速度

**实现方式**：
- 全相联映射
- 直接映射
- 组相联映射

**替换算法**：
- LRU
- FIFO
- LFU

### 9.3.2 提高磁盘I/O速度的其他方法
| 方法 | 说明 |
|------|------|
| **提前读** | 预测可能需要的数据，提前读入缓存 |
| **延迟写** | 将写操作延迟，批量写入磁盘 |
| **优化文件布局** | 将相关文件放在相邻的磁盘块 |
| **磁盘调度** | 选择最优的磁盘访问顺序 |
| **并行I/O** | 使用多个磁盘同时进行I/O操作 |

### 9.3.3 廉价磁盘冗余阵列（RAID）

**定义**：将多个磁盘组合成一个逻辑磁盘，提高存储性能和可靠性。

| 级别 | 技术 | 优点 | 缺点 |
|------|------|------|------|
| **RAID 0** | 条带化 | 性能高 | 无冗余，一块坏全丢 |
| **RAID 1** | 镜像 | 可靠性高 | 成本高（50%利用率） |
| **RAID 5** | 分布式奇偶校验 | 性能+可靠性平衡 | 写操作有开销 |
| **RAID 6** | 双重奇偶校验 | 可坏两块盘 | 写入更慢 |

**优点**：
- 提高存储性能
- 提高存储可靠性
- 增加存储容量

## 9.4 提高磁盘可靠性的技术
### 9.4.1 第一级容错技术
**第一级容错技术**是指用于检测和纠正磁盘错误的技术。

**方法**：
- **双份目录和双份文件分配表**：备份关键数据结构
- **热修复重定向**：将损坏的扇区重定向到备用扇区
- **写后读验证**：写入数据后立即读取验证

### 9.4.2 第二级容错技术
**第二级容错技术**是指用于处理磁盘故障的技术。

**方法**：
- **磁盘镜像**：将数据同时写入两个磁盘
- **磁盘双工**：使用两个独立的磁盘控制器
- **RAID技术**：使用冗余磁盘阵列

### 9.4.3 基于集群系统的容错技术
**基于集群系统的容错技术**是指通过多个服务器组成集群，提供高可用性。

**方法**：
- **故障转移**：当一个服务器故障时，另一个服务器接管
- **负载均衡**：将工作负载分配到多个服务器
- **数据复制**：在多个服务器之间复制数据

### 9.4.4 后备系统
**后备系统**是指用于备份数据的系统。

**类型**：
- **全备份**：备份所有数据
- **增量备份**：只备份自上次备份以来更改的数据
- **差异备份**：只备份自上次全备份以来更改的数据

**备份介质**：
- 磁带
- 光盘
- 外部硬盘
- 网络存储

## 9.5 存储新技术
### 9.5.1 传统存储系统
**传统存储系统**：
- **硬盘驱动器（HDD）**：使用机械部件存储数据
- **磁带存储**：用于长期备份
- **光盘存储**：用于分发和存档

**特点**：
- 容量大
- 成本低
- 速度相对较慢
- 易受物理损坏

### 9.5.2 新型存储系统
**新型存储系统**：
- **网络存储**：通过网络访问存储
  - **网络附加存储（NAS）**：专用存储服务器
  - **存储区域网络（SAN）**：高速存储网络
- **云存储**：通过互联网访问存储服务
- **分布式存储**：将数据分布在多个节点

**特点**：
- 高可用性
- 可扩展性
- 远程访问
- 按需付费

### 9.5.3 固态硬盘
**固态硬盘（SSD）**：使用闪存存储数据，没有机械部件。

**优点**：
- 速度快
- 能耗低
- 无噪音
- 抗震性好

**缺点**：
- 成本高
- 写入次数有限
- 容量相对较小

**类型**：
- **SATA SSD**：使用SATA接口
- **NVMe SSD**：使用PCIe接口，速度更快
- **M.2 SSD**：小型化设计

## 9.6 数据一致性控制
### 9.6.1 事务
**事务**是指一组操作，要么全部执行成功，要么全部不执行。

**特性**（ACID）：
- **原子性（Atomicity）**：事务是一个不可分割的单位
- **一致性（Consistency）**：事务执行前后数据保持一致
- **隔离性（Isolation）**：多个事务之间相互隔离
- **持久性（Durability）**：事务执行结果永久保存

**事务处理**：
- **开始事务**：标记事务的开始
- **提交事务**：将事务的结果永久保存
- **回滚事务**：取消事务的执行

### 9.6.2 检查点
**检查点**是指在事务处理过程中，将内存中的数据定期刷新到磁盘。

**目的**：
- 减少恢复时间
- 提高系统可靠性

**检查点机制**：
- 记录检查点时刻的系统状态
- 将脏页刷新到磁盘
- 记录检查点信息

### 9.6.3 并发控制
**并发控制**是指控制多个事务同时执行，避免数据不一致。

**方法**：
- **锁机制**：使用锁来控制对数据的访问
  - 共享锁（读锁）
  - 排他锁（写锁）
- **时间戳**：使用时间戳来解决冲突
- **乐观并发控制**：假设冲突很少，只在提交时检查冲突

### 9.6.4 重复数据的一致性问题
**重复数据**是指在多个位置存储相同的数据。

**一致性问题**：当一个位置的数据更新后，其他位置的数据可能不同步。

**解决方法**：
- **主从复制**：一个主副本，多个从副本
- **多主复制**：多个主副本，相互同步
- **一致性哈希**：将数据均匀分布到多个节点
- **最终一致性**：允许暂时的不一致，最终达到一致

## 9.7 本章小结
- 外存组织：连续 / 链接 / 索引
- 空闲空间管理：空闲表 / 空闲链表 / 位图 / 成组链接
- 磁盘缓存：利用局部性提高I/O速度
- RAID：条带化（性能） vs 镜像（可靠性）
- 数据一致性：事务ACID + 检查点 + 并发控制
