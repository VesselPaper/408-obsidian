# 第5章-传输层

## 5.1 传输层的基本概念

#第5章-传输层/传输层的基本概念
**传输层**负责端到端的通信，其协议通常在[[03-操作系统/第1章-操作系统概述|操作系统]]中实现。

**传输层的功能**：
- 端到端连接：建立和维护端到端的连接
- 流量控制：控制发送速率
- 差错控制：检测和纠正传输错误
- 复用和分用：多个应用共享传输层连接

## 5.2 TCP协议

#第5章-传输层/TCP协议
**TCP**是一种面向连接的、可靠的传输层协议。

**TCP的特点**：
- 面向连接：建立连接后传输数据
- 可靠传输：使用确认和重传机制
- 流量控制：使用滑动窗口机制
- 拥塞控制：根据网络状况调整发送速率
- 全双工通信：双向同时传输

**TCP的首部**：
- 源端口：源端口号
- 目的端口：目的端口号
- 序号：数据的序号
- 确认号：期望收到的下一个序号
- 数据偏移：首部长度
- 标志位：SYN、ACK、FIN等
- 窗口：滑动窗口大小
- 校验和：检查错误
- 紧急指针：紧急数据的位置

**TCP的连接建立**：三次握手
1. 客户端发送SYN包，序号为x
2. 服务器发送SYN+ACK包，序号为y，确认号为x+1
3. 客户端发送ACK包，序号为x+1，确认号为y+1

**TCP的连接释放**：四次挥手
1. 客户端发送FIN包，序号为u
2. 服务器发送ACK包，确认号为u+1
3. 服务器发送FIN包，序号为v
4. 客户端发送ACK包，确认号为v+1

**TCP的流量控制**：使用滑动窗口机制，根据接收方的缓冲区大小调整发送窗口

**TCP的拥塞控制**：
- 慢开始：初始拥塞窗口较小，逐渐增大
- 拥塞避免：拥塞窗口线性增长
- 快重传：收到重复确认后立即重传
- 快恢复：发生拥塞后快速恢复拥塞窗口

## 5.3 UDP协议

#第5章-传输层/UDP协议
**UDP**是一种无连接的、不可靠的传输层协议。

**UDP的特点**：
- 无连接：不需要建立连接
- 不可靠：不保证数据的可靠传输
- 面向报文：保留应用层报文的边界
- 无拥塞控制：不根据网络状况调整发送速率
- 开销小：首部简单

**UDP的首部**：
- 源端口：源端口号
- 目的端口：目的端口号
- 长度：UDP数据报的长度
- 校验和：检查错误

**UDP的应用场景**：
- 实时应用：如视频会议、在线游戏
- 简单请求-响应应用：如DNS
- 广播和多播应用

## 5.4 端口号

#第5章-传输层/端口号
**端口号**：16位的标识符，用于标识应用程序

**端口号的分类**：
- 熟知端口：0-1023，如HTTP的80端口
- 注册端口：1024-49151
- 动态端口：49152-65535

**常用端口号**：
- HTTP：80
- HTTPS：443
- FTP：21
- SMTP：25
- DNS：53
- SSH：22
