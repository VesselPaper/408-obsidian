# 第1章-计算机网络概述

> 计算机网络是计算机之间"沟通"的桥梁，让世界各地的计算机能够互相通信、共享资源。

## 1.1 计算机网络是什么？
#第1章-计算机网络概述/计算机网络的概念

**计算机网络**是将分散的计算机通过**通信设备**和**传输介质**连接起来，实现信息共享和资源共享的系统。

```
🌐 简单理解：计算机网络就像"蜘蛛网"，把很多电脑连在一起，大家可以互相发消息、传文件

实际例子：
你用手机刷微博 → 数据从微博服务器 → 经过很多网络设备 → 到你的手机
```

### 计算机网络的核心功能

| 功能 | 简单解释 | 例子 |
|------|----------|------|
| **数据通信** | 计算机之间传数据 | 发微信、聊QQ |
| **资源共享** | 大家共用硬件软件 | 共享打印机、共享文件 |
| **分布式处理** | 一件事多人做 | 百度网盘上传、云计算 |
| **提高可靠性** | 一台坏了还有别的 | 分布式存储 |
| **负载均衡** | 分散压力 | 双11购物分流 |

## 1.2 计算机网络的分类
#第1章-计算机网络概述/计算机网络的分类

### 按覆盖范围分类（最重要！）

```
覆盖范围示意：
┌─────────────────────────────────────────────────────────────┐
│                        广域网(WAN)                         │
│  ┌────────────────────────┐                                │
│  │     城域网(MAN)        │                                │
│  │  ┌──────────────────┐ │                                │
│  │  │    局域网(LAN)   │ │                                │
│  │  │  办公室/家庭    │ │                                │
│  │  └──────────────────┘ │                                │
│  └────────────────────────┘                                │
└─────────────────────────────────────────────────────────────┘
```

| 类型 | 覆盖范围 | 典型例子 |
|------|----------|----------|
| **局域网(LAN)** | 几十米~几公里 | 办公室网络、校园网 |
| **城域网(MAN)** | 几十公里 | 城市WiFi、城市有线电视 |
| **广域网(WAN)** | 跨城市/国家 | 互联网、移动网络 |

### 按拓扑结构分类

```
拓扑结构对比：

总线型：            星型：           环型：
   ○──○──○──○          ○             ○→○→○→○
   (一根线串连)       /│\             (单线连成环)
                    ○ ○ ○
   优点：简单        (中心节点)      优点：顺序传输
   缺点：一人坏全坏   优点：易管理     缺点：一环坏全坏
                    缺点：中心要稳定
```

| 结构 | 特点 | 缺点 |
|------|------|------|
| **总线型** | 所有设备接同一根线 | 单点故障 |
| **星型** | 所有设备连中心节点 | 依赖中心 |
| **环型** | 首尾相连成环 | 一环断全断 |
| **网状** | 多个节点互相连接 | 成本高 |

### 按传输技术分类

| 类型 | 说明 | 例子 |
|------|------|------|
| **广播式** | 一台发送，大家都能收到 | WiFi、收音机 |
| **点对点** | 一台发送，另一台专门接收 | 打电话、发邮件 |

## 1.3 网络体系结构（核心重点！）
#第1章-计算机网络概述/网络体系结构

### 为什么需要分层？

```
📌 简单理解：就像物流公司
- 寄件人 → 包装、填单（应用层）
- 快递员上门取件 → 运输（传输层）
- 分拨中心分拣 → 路由（网络层）
- 卡车/飞机运输 → 物理传输（数据链路层）
```

### OSI参考模型（7层）

```
从下到上记忆：
┌─────────────────────────────────────────────────────────┐
│ 7 应用层   ←→ 你用的软件（微信、浏览器）                │
├─────────────────────────────────────────────────────────┤
│ 6 表示层   ←→ 数据格式转换（加密解密）                 │
├─────────────────────────────────────────────────────────┤
│ 5 会话层   ←→ 管理会话（登录保持）                     │
├─────────────────────────────────────────────────────────┤
│ 4 传输层   ←→ 可靠传输（TCP/UDP）                      │
├─────────────────────────────────────────────────────────┤
│ 3 网络层   ←→ 路由选择（IP协议）                       │
├─────────────────────────────────────────────────────────┤
│ 2 数据链路层 ←→ 帧的传输、差错检测（MAC地址）          │
├─────────────────────────────────────────────────────────┤
│ 1 物理层   ←→ 比特流传输（网线、光纤）                  │
└─────────────────────────────────────────────────────────┘

📌 记忆口诀：应表会传网数物（谐音：应表会话网食物）
```

### TCP/IP模型（4层）

```
TCP/IP模型是对OSI的简化：

┌────────────────────────┐
│  应用层  (OSI 5/6/7)   │ ← HTTP、FTP、DNS
├────────────────────────┤
│  传输层  (OSI 4)       │ ← TCP、UDP
├────────────────────────┤
│  网络层  (OSI 3)       │ ← IP、ICMP
├────────────────────────┤
│  网络接口层 (OSI 1/2)  │ ← Ethernet、WiFi
└────────────────────────┘
```

### 数据传输过程（重要！）

```
发送数据过程（自上而下 + 封包）：

应用层：  "你好" 
         ↓ +端口      [数据]
传输层：  +TCP头      [TCP头|数据]
网络层：  +IP头       [IP头|TCP头|数据]
数据链路层：+MAC头+尾  [MAC头|IP头|TCP头|数据|FCS]
物理层：  转换成电信号/光信号
         ↓
    ───────────────────────────────────────▶
         ↓
接收数据过程（自下而上 + 解封）：
物理层：  电信号转二进制
数据链路层：检查MAC地址、校验FCS
网络层：  检查IP地址
传输层：  检查端口、重组数据
应用层：  "你好"
```

## 1.4 网络性能指标
#第1章-计算机网络概述/网络性能指标

### 核心指标

| 指标 | 含义 | 单位 |
|------|------|------|
| **带宽** | 单位时间能传多少数据 | bps (比特/秒) |
| **吞吐量** | 实际传输的数据量 | bps |
| **延迟** | 数据从发送到接收的时间 | ms (毫秒) |
| **丢包率** | 数据丢失的比例 | % |
| **带宽延迟积** | 带宽×延迟，决定管道大小 | bit |

### 延迟的组成

```
总延迟 = 发送延迟 + 传播延迟 + 处理延迟 + 排队延迟

发送延迟：把数据放到网络上的时间（数据长度/带宽）
传播延迟：数据在介质中传播的时间（距离/传播速度）
处理延迟：设备处理数据的时间
排队延迟：数据等待的时间
```

> 📌 **重要公式**：带宽延迟积 = 带宽 × 传播延迟
> - 表示"管道"能容纳多少数据
> - 带宽延迟积越大，网络利用效率越高

## 习题1（考研真题精选）

### 选择题

1. **【2011统考真题】** 在OSI参考模型中，网络层传输的是？
   A. 比特流  B. 帧  C. 分组  D. 报文  
   > **答案**：C  
   > **解析**：物理层-比特流，数据链路层-帧，网络层-分组，传输层-报文。

2. **【2013统考真题】** 在TCP/IP模型中，网络层的主要功能是？
   A. 差错控制  B. 路由选择  C. 可靠传输  D. 进程寻址  
   > **答案**：B  
   > **解析**：网络层（IP层）核心功能是路由选择。

3. **【2015统考真题】** 下列关于局域网和广域网的叙述，正确的是？
   A. 局域网只能使用以太网技术  
   B. 广域网主要用于连接不同城市的网络  
   C. 局域网带宽一定比广域网高  
   D. 广域网误码率一定比局域网高  
   > **答案**：B  
   > **解析**：广域网跨城市、跨国家，用于远距离连接。

4. **【2017统考真题】** 若网络带宽为100Mbps，传播延迟为10ms，则带宽延迟积为多少bit？
   A. 1000  B. 10000  C. 100000  D. 1000000  
   > **答案**：C  
   > **解析**：带宽延迟积 = 100×10⁶ × 10×10⁻³ = 10⁶ bit

5. **【2019统考真题】** OSI参考模型中，提供端到端可靠数据传输的是？
   A. 物理层  B. 数据链路层  C. 网络层  D. 传输层  
   > **答案**：D  
   > **解析**：传输层（TCP）提供端到端可靠传输。

### 综合应用题

6. **【2014统考真题】** 简述TCP/IP模型与OSI模型的区别。

**参考答案**：
1. TCP/IP模型只有4层，OSI模型有7层
2. TCP/IP模型更简洁实用，OSI模型理论更完整
3. TCP/IP模型的网络接口层对应OSI的物理层和数据链路层
4. TCP/IP模型的应用层对应OSI的会话层、表示层和应用层

7. **【2018统考真题】** 主机A向主机B发送一个大小为100KB的文件，假设网络带宽为10Mbps，传播延迟为20ms，问从A开始发送到B完全接收需要多长时间？（忽略处理和排队延迟）

**参考答案**：
```
发送延迟 = 数据大小 / 带宽
         = 100KB / 10Mbps
         = 100 × 1024 × 8 / (10 × 10⁶)
         = 819200 / 10000000 ≈ 82ms
         
总延迟 = 发送延迟 + 传播延迟 × 2
       = 82ms + 20ms × 2 = 122ms
       
（发送和传播可以重叠，所以是单程传播延迟）
```
