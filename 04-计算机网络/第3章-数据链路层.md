# 第3章-数据链路层

> 数据链路层负责在相邻两个节点之间可靠地传输"帧"，是"快递员"把包裹送到邻居家。

## 3.1 数据链路层概述
#第3章-数据链路层/概述

### 数据链路层做什么？

```
📌 简单理解：数据链路层就是"快递员"

物理层：把货物变成"信号"（比如光信号）
数据链路层：把信号打包成"包裹"（帧），可靠地送到下一个"驿站"（节点）

与物理层的关系：
- 物理层：比特的"搬运工"
- 数据链路层：帧的"快递员"
```

### 数据链路层的功能

| 功能 | 说明 |
|------|------|
| **封装成帧** | 把数据打包成"帧"（加头部尾部） |
| **差错检测** | 检查包裹是否损坏 |
| **流量控制** | 别送太快，接收方来不及收 |
| **介质访问控制** | 大家一起用网，怎么分配 |

## 3.2 封装成帧
#第3章-数据链路层/封装成帧

### 什么是帧？

```
以太网帧格式：

| 字段 | 前导码 | SFD | 目标MAC | 源MAC | 类型 | 数据 | FCS |
|------|--------|-----|---------|-------|------|------|-----|
| 字节数 | 7 | 1 | 6 | 6 | 2 | 46-1500 | 4 |
```

### 帧的定界方法

| 方法 | 说明 | 应用 |
|------|------|------|
| **字符计数法** | 第一个字符表示长度 | 很少用 |
| **字符填充法** | 用特殊字符标记开始结束 | PPP协议 |
| **零比特填充法** | 用01111110标记 | HDLC |
| **违规编码法** | 用违规的编码标记 | 以太网 |

## 3.3 差错检测
#第3章-数据链路层/差错检测

### 错误是怎么产生的？

```
原因：信号在传输过程中受干扰
    ┌─── 噪声 ───┐
    │            │
  发送：1 ──→  收到：0（错了！）
```

### 差错检测方法

```
1. 奇偶校验（太简单，不常用）
   发送：数据后面加1位"校验位"
   接收：数1的个数是否对
   
2. 循环冗余校验CRC（常用！）
   📌 考研重点
   
   原理：
   - 用多项式除法
   - 余数就是FCS
   - 接收方验证
```

> 📌 **CRC的特点**：能检测多位错误，但**不能纠错**！

### 可靠传输

```
错误处理方式：
- 检错重传（常用）：检测到错误 → 重传
- 纠错码（复杂）：直接纠正错误

常用协议：
- 停止-等待协议：发一个等一个确认
- 连续ARQ：连续发多个，错了重传
- 选择重传：只重传错的帧
```

## 3.4 介质访问控制
#第3章-数据链路层/介质访问控制

### 为什么会冲突？

```
📌 简单理解：大家一起用网线，撞车了

例子：多人同时说话
- 你说一句
- 我说一句
- 结果都听不清

解决方法：大家轮流说，不要抢
```

### 信道分配方式

| 方式 | 说明 | 代表协议 |
|------|------|----------|
| **静态分配** | 事先分配好，不冲突 | TDM、FDM |
| **动态分配** | 用的时候再分配 | ALOHA、CSMA |

### CSMA/CD（重要！）

```
📌 简单理解：先听再说，边说边听

CSMA/CD = 载波监听 + 碰撞检测 + 退避算法

工作流程：
1. 先监听：有其他人在说吗？
2. 如果没人说，我开始说
3. 说的同时监听：有碰撞吗？
4. 如果有碰撞，立即停止，并等一会再试

以太网用这个！
```

```
碰撞检测过程：
A检测到空闲，开始发送
B也检测到空闲，也开始发送
信号在网线中碰撞
A和B都检测到碰撞
停止发送，各自等待随机时间后重试
```

### 争用期

```
📌 考研重点：2τ（两倍传播时延）

- τ：信号从一端传到另一端的时间
- 2τ：信号往返时间

以太网的争用期：51.2μs
这意味着：
- 发送512比特的时间
- 如果512比特还没碰撞，就不会碰撞了
```

## 3.5 局域网
#第3章-数据链路层/局域网

### 以太网（最重要！）

```
📌 简单理解：最常用的局域网技术

以太网特点：
- 成本低
- 速率高（10Mbps~10Gbps）
- 采用CSMA/CD
- 广播方式
```

### MAC地址

```
📌 MAC地址 = 网卡的"身份证号"

格式：48位（6字节）
例：00-1B-2A-3C-4D-5E

分类：
- 单播地址：发给特定网卡
- 多播地址：发给一组网卡
- 广播地址：FF:FF:FF:FF:FF:FF（发给所有人）
```

### 以太网帧格式

```
以太网帧格式（IEEE 802.3）：

| 字段 | 前导码 | SFD | 目标MAC | 源MAC | 类型 | 数据 | FCS |
|------|--------|-----|---------|-------|------|------|-----|
| 字节数 | 7 | 1 | 6 | 6 | 2 | 46-1500 | 4 |

说明：
- 前导码：同步用
- SFD：帧开始定界符
- Type：类型（0800=IP，0806=ARP）
- FCS：CRC校验
```

## 3.6 交换机
#第3章-数据链路层/交换机

### 交换机 vs 集线器

```
集线器(Hub) vs 交换机(Switch)对比：

| 特性 | Hub | Switch |
|------|-----|--------|
| 工作层 | 物理层 | 数据链路层 |
| 转发方式 | 广播 | 按MAC地址转发 |
| 带宽 | 共享 | 独占 |
| 冲突域 | 所有端口一个 | 每个端口独立 |
| 性能 | 差 | 好 |
```

### 交换机的工作原理

```
1. 学习：
   收到帧 → 记录"谁在哪个端口"
   例：收到A的帧，记录"A在端口1"
   
2. 转发：
   查表 → 如果知道目标在哪 → 直接发到对应端口
   查表 → 如果不知道 → 广播（发给所有端口）
   
3. 更新：
   每条记录有超时（一般5分钟）
   超时删除，防止表太大
```

> 📌 **交换机可以隔离冲突域！**

## 习题3（考研真题精选）

### 选择题

1. **【2011统考真题】** 数据链路层的主要功能不包括？
   A. 路由选择  B. 帧定界  C. 差错检测  D. 流量控制  
   > **答案**：A  
   > **解析**：路由选择是网络层的功能。

2. **【2013统考真题】** 以太网采用的协议是？
   A. PPP  B. HDLC  C. CSMA/CD  D. TCP  
   > **答案**：C  
   > **解析**：以太网采用CSMA/CD协议。

3. **【2015统考真题】** 交换机和集线器的区别是？
   A. 交换机可以隔离冲突域  B. 集线器可以按MAC转发  
   C. 交换机工作在物理层  D. 集线器工作在数据链路层  
   > **答案**：A  
   > **解析**：交换机是数据链路层设备，可以隔离冲突域。

4. **【2017统考真题】** CRC校验中，如果接收方计算余数不为0，说明什么？
   A. 数据正确  B. 数据有错误  C. 校验码错误  D. 链路中断  
   > **答案**：B  
   > **解析**：CRC余数为0表示无错误，不为0表示有错误。

5. **【2019统考真题】** 下列关于CSMA/CD的说法，错误的是？
   A. 先监听再发送  B. 边发送边监听  C. 可以完全避免碰撞  D. 碰撞后退避重传  
   > **答案**：C  
   > **解析**：CSMA/CD不能完全避免碰撞，只能减少碰撞。

### 综合应用题

6. **【2014统考真题】** 简述CSMA/CD的工作原理，并说明其最小帧长的作用。

**参考答案**：
```
CSMA/CD工作原理：
1. 载波监听：发送前检测信道是否空闲
2. 碰撞检测：发送时检测是否发生碰撞
3. 退避算法：碰撞后等待随机时间再重试

最小帧长作用：
- 保证在发送完帧之前能检测到碰撞
- 以太网最小帧长64字节
- 保证发送时间>2τ（往返传播时间）
```

7. **【2018统考真题】** 某交换机MAC地址表为空，收到如下帧，请给出转发决策。

```
1. 目的MAC=A，端口1
2. 目的MAC=B，端口2  
3. 目的MAC=A，端口3
```

**参考答案**：
```
1. 收到A的帧，表中没有A → 广播（除端口1外）
   学习：A在端口1
2. 收到B的帧，表中没有B → 广播（除端口2外）
   学习：B在端口2
3. 收到A的帧，表中A在端口1 → 直接转发到端口1
   学习：A可能在端口3更新（实际保留原端口）
```
