# 第2章-物理层

> 物理层是计算机网络的最底层，负责把数据转换成信号，在物理介质上传输。

## 2.1 物理层概述
#第2章-物理层/物理层概述

### 物理层做什么？

```
📌 简单理解：物理层就是"修路"的

例子：两个人打电话
- 你说的话 → 声音 → 电话转换成电信号
- 电信号通过电话线传输
- 对方的电话把电信号转回声音

物理层就是负责这个"信号传输"的过程
```

### 物理层的4个特性

| 特性 | 说明 | 例子 |
|------|------|------|
| **机械特性** | 接口形状、尺寸 | USB接口、网线接口 |
| **电气特性** | 电压、电流 | 5V表示1，0V表示0 |
| **功能特性** | 引脚功能 | 每个引脚干什么 |
| **过程特性** | 顺序事件 | 谁先发、谁后发 |

## 2.2 数据通信基础
#第2章-物理层/数据通信

### 通信系统的组成

```
数据通信系统的组成：

| 组成部分 | 说明 | 例子 |
|----------|------|------|
| 信源 | 发送数据的设备 | 你的手机 |
| 发送器 | 将数据转换为信号 | 调制器 |
| 信道 | 传输信号的通道 | 网线/空气 |
| 接收器 | 将信号转换为数据 | 解调器 |
| 信宿 | 接收数据的设备 | 对方手机 |
```

### 数据的传输方式

```
按方向分：
- 单工：只能A→B（电视遥控）
- 半双工：A→B 或 B→A，但不能同时（对讲机）
- 全双工：A↔B 同时（电话）

按并行度分：
- 串行传输：1位1位地传（网线）
- 并行传输：多位同时传（并口）→ 距离近
```

### 重要概念

| 概念 | 说明 | 关系 |
|------|------|------|
| **码元** | 一个"波形" | 数字信号基本单位 |
| **波特率** | 每秒多少个码元 | 码元/秒 |
| **比特率** | 每秒多少比特 | 比特/秒 |
| **带宽** | 能传多少数据 | 取决于信道 |

```
📌 重要公式：
比特率 = 波特率 × log₂(每个码元多少种状态)

例：二进制，每个码元2种状态
波特率=1000，则比特率=1000×1=1000bps
例：四进制，每个码元4种状态
波特率=1000，则比特率=1000×2=2000bps
```

## 2.3 传输介质
#第2章-物理层/传输介质

### 导向传输介质（有形的线）

| 介质 | 特点 | 速率 | 距离 | 应用 |
|------|------|------|------|------|
| **双绞线** | 两根线绞在一起，抗干扰 | 10Mbps~10Gbps | 100m | 局域网 |
| **同轴电缆** | 铜芯+屏蔽层 | 100Mbps | 200m | 有线电视 |
| **光纤** | 光信号传输 | 10Gbps~100Tbps | 几十km | 骨干网 |

```
光纤对比：

| 特性 | 单模光纤 | 多模光纤 |
|------|----------|----------|
| 核心直径 | 8-10μm | 50-100μm |
| 传输模式 | 一束光 | 多束光 |
| 距离 | 几十km | 几百米 |
| 成本 | 高 | 低 |
| 应用 | 远程骨干网 | 局域网 |
```

### 非导向传输介质（无线的）

| 介质 | 频率 | 特点 |
|------|------|------|
| **无线电波** | 30Hz~3GHz | 绕射能力强，覆盖广 |
| **微波** | 3GHz~300GHz | 直线传播，需中继 |
| **红外线** | 300GHz~400THz | 直线传播，不能穿墙 |
| **可见光** | 400THz~800THz | 最新的光通信 |

## 2.4 编码与调制
#第2章-物理层/编码与调制

### 什么是编码？

编码就是把**数字数据**转换成**数字信号**：

```
数字数据：01011
    ↓ 编码
数字信号：┌─┐┌┐┌─┐┌┐
         ┌┘ └┘└┘ └┘ 
```

### 常见编码方式

```
1. 非归零码（NRZ）：
   1  0  0  1  1  0
   ┌──┐  ┌──┐┌──┐
   │  │  │  ││  │
───┘  └──┘ └──┘ └──
   缺点：无法判断码元开始和结束

2. 曼彻斯特编码（以太网用）：
   1  0  1  1  0  0
   ┌┐ ┌┐┌┐ ┌──┐
   │└┘│└┘└┐│  │
───┘  └┘  └──┘ 
   特点：每比特中间有跳变，可同步
```

> 📌 **考研重点**：曼彻斯特编码常用于以太网

### 什么是调制？

调制就是把**数字数据**转换成**模拟信号**：

```
数字数据：01011
    ↓ 调制
模拟信号：~~波形~~~
```

### 调制方式

| 方式 | 原理 | 特点 |
|------|------|------|
| **ASK** | 幅度变化 | 有幅度=1，无幅度=0 |
| **FSK** | 频率变化 | 频率高=1，频率低=0 |
| **PSK** | 相位变化 | 相位变化表示01 |
| **QAM** | 幅度+相位 | 组合，效率最高 |

```
📌 简单理解：
- ASK：声音大小变化
- FSK：音调高低变化
- PSK：声音开始的时间变化
- QAM：多个组合
```

## 2.5 物理层设备
#第2章-物理层/物理层设备

### 中继器

```
📌 简单理解：信号"放大器"

作用：接收信号，重新生成，发射出去
原因：信号传输会衰减

距离限制：
- 以太网：最大500m（细缆）
- 加中继器后：可达2500m
```

### 集线器（Hub）

```
集线器（Hub）特点：

| 特性 | 说明 |
|------|------|
| 类型 | 多端口中继器 |
| 连接 | 连接多台电脑 |
| 通信方式 | 半双工 |
| 转发方式 | 广播（发给所有端口） |
| 冲突域 | 所有端口在同一冲突域 |
```

> ⚠️ **注意**：集线器是物理层设备，不处理MAC地址！

## 习题2（考研真题精选）

### 选择题

1. **【2011统考真题】** 物理层的主要功能是？
   A. 比特同步  B. 比特编码  C. 路由选择  D. 差错控制  
   > **答案**：B  
   > **解析**：物理层主要功能是比特编码和调制。

2. **【2013统考真题】** 10Base-T以太网采用的传输介质是？
   A. 光纤  B. 双绞线  C. 同轴电缆  D. 无线电  
   > **答案**：B  
   > **解析**：10Base-T的T表示双绞线 Twisted Pair。

3. **2015统考真题】** 曼彻斯特编码的效率是？
   A. 50%  B. 75%  C. 100%  D. 200%  
   > **答案**：A  
   > **解析**：曼彻斯特编码每比特需要2个码元，效率50%。

4. **【2017统考真题】** 下列传输介质中，抗干扰能力最强的是？
   A. 双绞线  B. 同轴电缆  C. 光纤  D. 无线电  
   > **答案**：C  
   > **解析**：光纤不受电磁干扰。

5. **【2019统考真题】** 若某链路的带宽为100MHz，采用4进制信号，则该链路的比特率是？
   A. 100Mbps  B. 200Mbps  C. 400Mbps  D. 800Mbps  
   > **答案**：C  
   > **解析**：4进制=log₂4=2比特/码元，比特率=100×2=200MBd×2=400Mbps。

### 综合应用题

6. **【2014统考真题】** 画出二进制序列10110101的曼彻斯特编码波形。

**参考答案**：
```
二进制：1  0  1  1  0  1  0  1
曼彻斯特（从高到低跳变为1）：
   ┌┐ ┌──┐┌┐ ┌──┐┌┐ ┌──┐
   │└┘│  ││└┘│  ││└┘│  │└┘
───┘  └──┘└  └──┘└  └──┘└  └──
```

7. **【2018统考真题】** 比较中继器和集线器的异同。

**参考答案**：
```
相同点：
- 都是物理层设备
- 都能放大信号、延长传输距离

不同点：
- 中继器：2个端口
- 集线器：多个端口
- 集线器会广播，集线器不处理任何地址
```
