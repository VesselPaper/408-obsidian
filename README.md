# 🖥️ 408 考研笔记

计算机学科专业基础综合（408）考研复习笔记，基于 **Obsidian + Claude Code** 构建，涵盖四门核心科目，随复习进度持续更新。

## 🎯 学习方法

我比较喜欢**输出式学习**（听课容易睡着），所以这套笔记的工作流是：

1. AI 先生成一份完整的笔记大纲
2. 我结合自己的学习理解、做的真题、与 AI 的问答讨论，逐步完善笔记内容

目前大部分笔记由 AI 辅助整理编写，我正在系统学习操作系统相关知识，后续会结合个人理解，逐步查漏补缺、扩充内容，持续完善整个项目。
