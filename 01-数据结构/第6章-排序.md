## 6.1 排序的基本概念
#第6章-排序/排序的基本概念

### 什么是排序？

```
📌 简单理解：排序就是"从小到大"或"从大到小"排列数据

排序前：[5, 3, 8, 1, 9]
排序后：[1, 3, 5, 8, 9]
```

### 排序的分类

| 分类方式 | 类型 | 说明 |
|----------|------|------|
| **按存储位置** | 内部排序 | 数据全部在内存中 |
| | 外部排序 | 需要读写外部存储 |
| **按比较方式** | 比较排序 | 基于元素比较 |
| | 非比较排序 | 桶排序、基数排序 |

### 排序的稳定性（重要！）

```
📌 考研重点：稳定性是指排序后相等元素的相对顺序是否改变

不稳定示例：
[2, 1, 2*, 3] → 排序后 → [1, 2*, 2, 3]
                         ↑ 相等的2顺序变了

稳定示例：
[2, 1, 2*, 3] → 排序后 → [1, 2, 2*, 3]
                         ↑ 相等的2顺序不变
```

| 算法 | 稳定性 |
|------|--------|
| 冒泡排序 | ✅ 稳定 |
| 插入排序 | ✅ 稳定 |
| 归并排序 | ✅ 稳定 |
| 快速排序 | ❌ 不稳定 |
| 堆排序 | ❌ 不稳定 |
| 希尔排序 | ❌ 不稳定 |
| 选择排序 | ❌ 不稳定 |
| 基数排序 | ✅ 稳定 |

## 6.2 插入排序
#第6章-排序/插入排序

### 直接插入排序

```
📌 简单理解：像打扑克牌一样，每次新抽一张牌，插入到正确位置

示例：[4, 5, 7, 2, 3]
步骤：
1. [4, 5, 7, 2, 3] → 假设前4个已排好，插入2
2. 从后往前比较：2<7→7后移，2<5→5后移，2<4→4后移
3. 插入到位置0
结果：[2, 4, 5, 7, 3]
```

```c
void InsertSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int temp = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > temp) {
            a[j+1] = a[j];  // 元素后移
            j--;
        }
        a[j+1] = temp;
    }
}
```

**特点**：
- 时间复杂度：O(n²)（最好O(n)，基本有序时）
- 空间复杂度：O(1)
- 稳定性：✅ 稳定
- 适用场景：**基本有序**的小规模数据

### 希尔排序（重要！）

```
📌 简单理解：分组进行插入排序，逐步减少分组

示例：[8, 9, 7, 6, 5, 4, 3, 2, 1]
第一趟（增量5）：8,4 → 4,8；9,3 → 3,9；7,2 → 2,7；6,5 → 5,6
              → [4, 3, 2, 5, 8, 9, 7, 6, 1]
第二趟（增量2）：分组排序...
第三趟（增量1）：最终排序
```

```c
void ShellSort(int a[], int n) {
    for (int gap = n/2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int temp = a[i];
            int j = i - gap;
            while (j >= 0 && a[j] > temp) {
                a[j+gap] = a[j];
                j -= gap;
            }
            a[j+gap] = temp;
        }
    }
}
```

**特点**：
- 时间复杂度：O(n^1.3)~O(n²)
- 空间复杂度：O(1)
- 稳定性：❌ 不稳定

## 6.3 交换排序
#第6章-排序/交换排序

### 冒泡排序（基础！）

```
📌 简单理解：像气泡一样，最大的元素慢慢"冒"到最后

示例：[5, 1, 4, 2, 8]
第一趟：[1, 4, 2, 5, 8] → 5冒到最后
第二趟：[1, 2, 4, 5, 8] → 4冒到位置3
...
```

```c
void BubbleSort(int a[], int n) {
    for (int i = 0; i < n-1; i++) {
        bool flag = false;
        for (int j = 0; j < n-i-1; j++) {
            if (a[j] > a[j+1]) {
                swap(&a[j], &a[j+1]);
                flag = true;
            }
        }
        if (!flag) break;  // 已排序，提前结束
    }
}
```

**特点**：
- 时间复杂度：O(n²)
- 空间复杂度：O(1)
- 稳定性：✅ 稳定

### 快速排序（核心重点！）

```
📌 简单理解：选一个"基准"，把数组分成两部分，左边都比基准小，右边都比基准大

示例：[6, 1, 2, 7, 9, 3, 4, 5, 10, 8]
选6为基准，分区后：[5, 1, 2, 4, 3] 6 [7, 9, 10, 8]
然后对左右两部分递归排序
```

```c
// 分区函数
int Partition(int a[], int low, int high) {
    int pivot = a[low];  // 选第一个为基准
    while (low < high) {
        while (low < high && a[high] >= pivot) high--;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];
    }
    a[low] = pivot;
    return low;
}

// 快速排序
void QuickSort(int a[], int low, int high) {
    if (low < high) {
        int pivot = Partition(a, low, high);
        QuickSort(a, low, pivot-1);
        QuickSort(a, pivot+1, high);
    }
}
```

**特点**：
- 时间复杂度：平均O(nlogn)，最坏O(n²)
- 空间复杂度：O(logn)（递归栈）
- 稳定性：❌ 不稳定

> 📌 **考研重点**：快速排序是考察最多的排序算法！

## 6.4 选择排序
#第6章-排序/选择排序

### 简单选择排序

```
📌 简单理解：每次选择最小的放到前面

示例：[5, 3, 8, 1]
第一趟：找最小1，与5交换 → [1, 3, 8, 5]
第二趟：找最小3，不变 → [1, 3, 8, 5]
第三趟：找最小5，与8交换 → [1, 3, 5, 8]
```

```c
void SelectSort(int a[], int n) {
    for (int i = 0; i < n-1; i++) {
        int min = i;
        for (int j = i+1; j < n; j++) {
            if (a[j] < a[min]) min = j;
        }
        if (min != i) swap(&a[i], &a[min]);
    }
}
```

### 堆排序（重要！）

```
📌 简单理解：利用"堆"的特性进行排序

堆的性质：
- 大根堆：父节点 ≥ 子节点
- 小根堆：父节点 ≤ 子节点

堆排序步骤：
1. 把数组建成大根堆
2. 堆顶（最大）与堆尾交换
3. 把剩余部分调整成大根堆
4. 重复2-3
```

```c
// 调整堆
void Heapify(int a[], int n, int i) {
    int largest = i;
    int left = 2*i + 1;
    int right = 2*i + 2;
    
    if (left < n && a[left] > a[largest]) largest = left;
    if (right < n && a[right] > a[largest]) largest = right;
    
    if (largest != i) {
        swap(&a[i], &a[largest]);
        Heapify(a, n, largest);
    }
}

// 堆排序
void HeapSort(int a[], int n) {
    // 1. 建堆
    for (int i = n/2 - 1; i >= 0; i--) {
        Heapify(a, n, i);
    }
    // 2. 交换并调整
    for (int i = n-1; i > 0; i--) {
        swap(&a[0], &a[i]);
        Heapify(a, i, 0);
    }
}
```

**特点**：
- 时间复杂度：O(nlogn)
- 空间复杂度：O(1)
- 稳定性：❌ 不稳定

## 6.5 归并排序（重要！）
#第6章-排序/归并排序

### 归并排序

```
📌 简单理解："分治法"，先把数组分成两部分，分别排序，再合并

示例：[5, 2, 8, 1, 9, 3]
分解：[5,2,8] 和 [1,9,3]
再分：[5,2] [8] 和 [1,9] [3]
再分：[5] [2] [8] [1] [9] [3]
合并：[2,5] [1,3,9] → [1,2,3,5,9]
```

```c
// 合并两个有序数组
void Merge(int a[], int low, int mid, int high) {
    int *temp = malloc((high-low+1) * sizeof(int));
    int i = low, j = mid+1, k = 0;
    
    while (i <= mid && j <= high) {
        if (a[i] <= a[j]) temp[k++] = a[i++];
        else temp[k++] = a[j++];
    }
    while (i <= mid) temp[k++] = a[i++];
    while (j <= high) temp[k++] = a[j++];
    
    for (i = low, k = 0; i <= high; i++) a[i] = temp[k++];
    free(temp);
}

// 归并排序
void MergeSort(int a[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(a, low, mid);
        MergeSort(a, mid+1, high);
        Merge(a, low, mid, high);
    }
}
```

**特点**：
- 时间复杂度：O(nlogn)（任何情况都是！）
- 空间复杂度：O(n)
- 稳定性：✅ 稳定
- 适用场景：**需要稳定排序**的大数据

## 6.6 基数排序
#第6章-排序/基数排序

### 基数排序

```
📌 简单理解：按"位"排序，从低位到高位

示例：[329, 457, 657, 839, 436, 720, 355]
按个位：720, 355, 436, 457, 657, 329, 839
按十位：720, 329, 436, 839, 355, 457, 657
按百位：329, 355, 436, 457, 657, 720, 839

结果：[329, 355, 436, 457, 657, 720, 839]
```

```c
void RadixSort(int a[], int n) {
    int max = a[0];
    for (int i = 1; i < n; i++) 
        if (a[i] > max) max = a[i];
    
    int radix = 1;
    while (max / radix > 0) {
        int count[10] = {0};
        int *temp = malloc(n * sizeof(int));
        
        // 计数
        for (int i = 0; i < n; i++) 
            count[(a[i] / radix) % 10]++;
        for (int i = 1; i < 10; i++) 
            count[i] += count[i-1];
        
        // 收集
        for (int i = n-1; i >= 0; i--) {
            int k = (a[i] / radix) % 10;
            temp[--count[k]] = a[i];
        }
        
        for (int i = 0; i < n; i++) a[i] = temp[i];
        radix *= 10;
        free(temp);
    }
}
```

**特点**：
- 时间复杂度：O(d(n+r))，d是位数，r是基数
- 空间复杂度：O(n+r)
- 稳定性：✅ 稳定

## 6.7 排序算法对比（重要！）
#第6章-排序/算法对比

### 综合对比表

| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 | 适用场景 |
|------|----------|----------|------|--------|----------|
| **直接插入** | O(n²) | O(n²) | O(1) | ✅ | 基本有序 |
| **希尔排序** | O(n^1.3) | O(n²) | O(1) | ❌ | 中等规模 |
| **冒泡排序** | O(n²) | O(n²) | O(1) | ✅ | 教学用 |
| **快速排序** | O(nlogn) | O(n²) | O(logn) | ❌ | 大数据 |
| **选择排序** | O(n²) | O(n²) | O(1) | ❌ | 小规模 |
| **堆排序** | O(nlogn) | O(nlogn) | O(1) | ❌ | 大数据 |
| **归并排序** | O(nlogn) | O(nlogn) | O(n) | ✅ | 大数据/外排序 |
| **基数排序** | O(d(n+r)) | O(d(n+r)) | O(r) | ✅ | 整数 |

### 考研选择技巧

```
📌 考研常见问题："哪种排序算法最适合XXX情况？"

1. 数据基本有序 → 直接插入排序
2. 数据随机分布 → 快速排序
3. 要求稳定排序 → 归并排序
4. 要求空间O(1) → 堆排序
5. 数据范围小 → 计数排序/桶排序
6. 整数排序 → 基数排序
```

8. **【2018统考真题】** 设计一个算法，在n个整数中找出前k大的数，要求时间复杂度O(nlogk)。

**参考答案**：
```
思路：使用大小为k的小根堆
1. 取前k个元素建小根堆
2. 遍历剩余元素：
   - 若比堆顶大，则替换堆顶并调整堆
3. 最终堆中即为前k大的数

时间复杂度：O(nlogk)
空间复杂度：O(k)
```
