# 第3章-树和二叉树

> 树是一种重要的非线性结构，比线性表更复杂，能表示层次关系。本章是数据结构的核心章节，考研必考！

## 3.1 树的基本概念
#第3章-树和二叉树/树的基本概念

### 什么是树？

```
📌 简单理解：树就像公司的组织结构，有层级关系
          A(老板)
         /│\
        B C D(经理)
       /│  │
      E F  G(员工)

特点：
- 有且只有一个"根节点"（A）
- 每个节点可能有多个"孩子"（子节点）
- 每个节点有且只有一个"父亲"（父节点）
- 没有父节点的叫"根节点"
- 没有子节点的叫"叶子节点"
```

### 树的基本术语

| 术语 | 含义 | 举例 |
|------|------|------|
| **节点** | 树中的每个元素 | A、B、C... |
| **根节点** | 没有父节点的节点 | A |
| **叶子节点** | 没有子节点的节点 | E、F、G |
| **父节点/子节点** | 节点的直接上层/下层 | A是B的父节点 |
| **度** | 节点有多少个子节点 | A的度=3 |
| **树的度** | 所有节点中最大的度 | 3 |
| **深度** | 从根到该节点的层数 | E的深度=2 |
| **高度** | 从该节点到最远叶子节点的层数 | A的高度=3 |

### 树的性质

```
📌 重要性质（考研常考！）：

1. 树中的节点数 = 所有节点的度数之和 + 1
   例：总度数=4，节点数=5

2. 度为m的树中，第i层最多有 m^(i-1) 个节点
   例：3叉树，第3层最多有 3²=9 个节点

3. 高度为h的m叉树，最多有 (m^h-1)/(m-1) 个节点
   例：3叉树，高3层，最多 (3³-1)/(3-1)=13 个节点
```

## 3.2 二叉树（重点！）
#第3章-树和二叉树/二叉树

### 什么是二叉树？

二叉树是每个节点**最多有两个子节点**的树：

```
二叉树示意图：

        A
       / \
      B   C
     / \   \
    D   E   F
    
A的度=2（有两个孩子）
B、C的度分别为2和1
D、E、F是叶子节点
```

### 二叉树的5个重要性质（必记！）

```
1. 第i层最多有 2^(i-1) 个节点
   例：第3层最多有 2^(3-1)=4 个节点

2. 深度为k的二叉树最多有 2^k - 1 个节点
   例：深度4的二叉树最多有 2^4-1=15 个节点

3. 任意二叉树，叶子节点数 = 度为2的节点数 + 1
   n0 = n2 + 1（考研常用公式！）

4. 完全二叉树的深度 = ⌊log₂n⌋ + 1
   例：10个节点的完全二叉树，深度=⌊log₂10⌋+1=4

5. 完全二叉树的父子关系：
   - 父节点：i/2
   - 左孩子：2i
   - 右孩子：2i+1
```

### 特殊二叉树

```
满二叉树 vs 完全二叉树：

满二叉树：               完全二叉树：
    ○                        ○
   / \                      / \
  ○   ○                     ○   ○
 / \                       / \
○   ○                     ○   ○
   ↑                       ↑
所有层都满               只有最后一层不满，从左到右
```

| 类型 | 特点 |
|------|------|
| **满二叉树** | 所有叶子都在最后一层，且每个非叶子都有两个子 |
| **完全二叉树** | 除了最后一层，其他层都满，且最后一层从左到右 |
| **平衡二叉树** | 左右子树高度差≤1，用于高效查找 |
| **二叉排序树** | 左子树<根<右子树，用于查找 |

### 二叉树的存储

```c
// 链式存储（最常用）
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild;  // 左孩子
    struct BiTNode *rchild;  // 右孩子
} BiTNode, *BiTree;

// 顺序存储（适合完全二叉树）
// 下标从1开始：data[1]是根
// i的左孩子：2i，右孩子：2i+1，父节点：i/2
```

## 3.3 二叉树的遍历（核心重点！）
#第3章-树和二叉树/二叉树的遍历

### 遍历方式

```
遍历示例树：

        A
       / \
      B   C
     / \   \
    D   E   F

四种遍历方式：

前序遍历（根-左-右）：A B D E C F
中序遍历（左-根-右）：D B E A C F
后序遍历（左-右-根）：D E B C F
层序遍历（按层）：   A B C D E F

📌 记忆口诀：
- 前：根在前面 → 根左右
- 中：根在中间 → 左根右  
- 后：根在后面 → 左右根
```

### 遍历实现

```c
// 前序遍历
void PreOrder(BiTree T) {
    if (T) {
        visit(T);           // 访问根
        PreOrder(T->lchild); // 遍历左子树
        PreOrder(T->rchild); // 遍历右子树
    }
}

// 中序遍历
void InOrder(BiTree T) {
    if (T) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}

// 后序遍历
void PostOrder(BiTree T) {
    if (T) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T);
    }
}

// 层序遍历（用队列）
void LevelOrder(BiTree T) {
    Queue Q;
    InitQueue(&Q);
    EnQueue(&Q, T);
    while (!IsEmpty(Q)) {
        DeQueue(&Q, p);
        visit(p);
        if (p->lchild) EnQueue(&Q, p->lchild);
        if (p->rchild) EnQueue(&Q, p->rchild);
    }
}
```

> 📌 **考研常考**：已知遍历序列，求其他遍历序列

## 3.4 二叉排序树（BST）
#第3章-树和二叉树/二叉排序树

### 什么是二叉排序树？

```
二叉排序树（左小右大）：

        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13

特点：
- 左子树所有节点 < 根节点
- 右子树所有节点 > 根节点
- 左右子树也是二叉排序树

查找效率：平均 O(logn)，最坏 O(n)（退化为链表）
```

### 操作

```c
// 查找
BiTree Search(BiTree T, KeyType key) {
    if (!T || T->key == key) return T;
    if (key < T->key) return Search(T->lchild, key);
    else return Search(T->rchild, key);
}

// 插入
void Insert(BiTree *T, KeyType key) {
    if (!*T) {
        *T = (BiTree)malloc(sizeof(BiTNode));
        (*T)->key = key;
        (*T)->lchild = (*T)->rchild = NULL;
    } else if (key < (*T)->key) {
        Insert(&(*T)->lchild, key);
    } else {
        Insert(&(*T)->rchild, key);
    }
}
```

## 3.5 平衡二叉树（AVL）
#第3章-树和二叉树/平衡二叉树

### 什么是平衡二叉树？

平衡二叉树是左右子树**高度差不超过1**的二叉排序树：

```
不平衡情况：          平衡后：
      8                  6
     /                  / \
    6        →        4   8
   /                  /
  4                  4
(高度差=2)           (高度差=1)
```

### 平衡调整（4种旋转）

```
📌 记忆口诀：
LL型：左左情况，向右旋转
RR型：右右情况，向左旋转
LR型：左右情况，先左旋后右旋
RL型：右左情况，先右旋后左旋

图示：

LL旋转：        RR旋转：
   a              a
  /              \
 b       →       b
/                 \
c                   c

LR旋转：        RL旋转：
   a              a
  /              /
 b      →       b
  \              \
   c              c
```

## 3.6 线索二叉树
#第3章-树和二叉树/线索二叉树

线索二叉树是利用空指针存储**前驱和后继**的二叉树：

```
中序线索二叉树示例：

        *
       / \
      *   *
     /     *
    *       *
   
* 表示有线索（指向前驱或后继）
优点：遍历不需要递归或栈
```

## 3.8 哈夫曼树（重要！）
#第3章-树和二叉树/哈夫曼树

### 什么是哈夫曼树？

哈夫曼树是**带权路径长度最小**的二叉树：

```
带权路径长度 WPL = Σ(权值 × 路径长度)

例：权值 A=7, B=5, C=2

方案1：               方案2（最优）：
   (14)                 (12)
   /  \                /  \
  7   (7)              7   5
      / \              / \
     5   2            2   (5)
                       \
                        2

WPL=7×1+5×2+2×3=23   WPL=7×2+5×2+2×2=28 ❌

不对，让我重新计算：

最优哈夫曼树：
     (14)
     /  \
    7    (7)
        /  \
       5    2
        
WPL = 7×1 + 5×2 + 2×2 = 7 + 10 + 4 = 21（最优！）
```

### 哈夫曼编码

```
哈夫曼编码是一种前缀编码（任何编码都不是其他编码的前缀）

示例：字符 A,B,C,D,E 权值分别为 7,5,2,2,1

编码结果（示例）：
A: 0
B: 11
C: 100
D: 101
E: 1101

特点：高频字符用短编码，节省空间
应用：数据压缩（ZIP、JPEG、MPEG）
```

## 习题3（考研真题精选）

### 选择题

1. **【2011统考真题】** 一棵度为4的树，其度为4、3、2、1的节点数分别为1、1、2、3，则该树的叶子节点数是？
   A. 6  B. 7  C. 8  D. 9  
   > **答案**：C  
   > **解析**：n = n1+n2+n3+n4+1 = 1+1+2+3+1 = 8

2. **【2013统考真题】** 某二叉树的前序序列为ABC，中序序列为BAC，则该二叉树的后序序列是？
   A. CBA  B. BCA  C. ACB  D. ABC  
   > **答案**：B  
   > **解析**：前序ABC说明A是根，中序BAC说明B是左孩子，C是右孩子，后序为BCA。

3. **【2015统考真题】** 一棵完全二叉树有1001个节点，则该二叉树中叶子节点数为？
   A. 500  B. 501  C. 502  D. 503  
   > **答案**：B  
   > **解析**：完全二叉树，n=1001，度为1的节点要么0要么1。此处度为1的节点=0，所以n0 = (n+1)/2 = 501。

4. **【2017统考真题】** 哈夫曼树的带权路径长度为27，权值分别为2,3,4,7，则该树的节点数为？
   A. 9  B. 10  C. 11  D. 12  
   > **答案**：A  
   > **解析**：n个权值生成哈夫曼树，有2n-1个节点。

### 综合应用题

5. **【2014统考真题】** 已知二叉树的中序序列为DBGEAFHC，后序序列为DGHEFBCA，请画出该二叉树。

**参考答案**：
```
首先，后序最后是A，所以A是根
中序中DBGE是左子树，FHCE是右子树
后序中DGHEF在左子树，BCA在右子树

按此分析，二叉树为：

        A
       / \
      B   C
     /   / \
    D   E   F
       / \
      G   H
```

6. **【2018统考真题】** 设计一个算法，判断一棵二叉树是否是平衡二叉树。

**参考答案**：
```c
bool isBalanced(BiTree T, int *height) {
    if (!T) {
        *height = 0;
        return true;
    }
    int left, right;
    if (!isBalanced(T->lchild, &left)) return false;
    if (!isBalanced(T->rchild, &right)) return false;
    if (abs(left - right) > 1) return false;
    *height = max(left, right) + 1;
    return true;
}
```

> **本章小结**
> 1. 树是层次结构，二叉树每个节点最多两个子节点
> 2. 二叉树性质：n0=n2+1，第i层最多2^(i-1)个节点
> 3. 遍历方式：前序（根左右）、中序（左根右）、后序（左右根）
> 4. 二叉排序树：左小右大，用于高效查找
> 5. 平衡二叉树：防止退化成链表，保证查找效率O(logn)
> 6. 哈夫曼树：WPL最小，用于数据压缩
