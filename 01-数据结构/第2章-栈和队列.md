# 第2章 栈和队列

> 栈和队列是两种特殊的线性表，它们限制了数据的访问位置。栈是"后进先出"，队列是"先进先出"。

## 2.1 栈（Stack）
#第2章-栈和队列/栈

### 什么是栈？
栈是一种**受限的线性表**，只能在一端（栈顶）进行插入和删除操作。

```
📌 简单理解：就像叠盘子，最后放的盘子最先被拿走
```

**核心特点**：后进先出（**LIFO**：Last In First Out）

```
栈的示意图：
        ┌───────┐
  入栈  │  新数据 │ ← 栈顶(top)
        ├───────┤
        │ 数据3  │
        ├───────┤
        │ 数据2  │
        ├───────┤
        │ 数据1  │ ← 栈底(bottom)
        └───────┘
        
操作示例：
Push(A) → [A]
Push(B) → [A,B]
Push(C) → [A,B,C]     ← C在栈顶
Pop()   → 返回C       ← 最后进的先出
```

### 栈的基本操作

| 操作 | 说明 | 时间复杂度 |
|------|------|------------|
| `Push(x)` | 入栈，把x压入栈顶 | O(1) |
| `Pop()` | 出栈，弹出栈顶元素 | O(1) |
| `GetTop()` | 查看栈顶元素（不删除） | O(1) |
| `IsEmpty()` | 判断栈是否为空 | O(1) |
| `Clear()` | 清空栈 | O(n) |

### 栈的顺序存储实现（顺序栈）

```c
#define MAXSIZE 100

typedef struct {
    ElemType data[MAXSIZE];  // 存放元素的数组
    int top;                  // 栈顶指针（-1表示空栈）
} SqStack;

// 初始化
void InitStack(SqStack *S) {
    S->top = -1;  // 栈为空
}

// 入栈
int Push(SqStack *S, ElemType x) {
    if (S->top == MAXSIZE - 1) return 0;  // 栈满
    S->data[++S->top] = x;  // 先移动指针，再存数据
    return 1;
}

// 出栈
int Pop(SqStack *S, ElemType *x) {
    if (S->top == -1) return 0;  // 栈空
    *x = S->data[S->top--];      // 先取数据，再移动指针
    return 1;
}

// 获取栈顶
int GetTop(SqStack *S, ElemType *x) {
    if (S->top == -1) return 0;
    *x = S->data[S->top];
    return 1;
}
```

### 栈的链式存储实现（链式栈）

```c
typedef struct StackNode {
    ElemType data;
    struct StackNode *next;
} StackNode, *LinkStack;

// 入栈（头插法）
void Push(LinkStack *S, ElemType x) {
    StackNode *p = (StackNode *)malloc(sizeof(StackNode));
    p->data = x;
    p->next = *S;   // 新节点指向原来的栈顶
    *S = p;         // 栈顶指向新节点
}

// 出栈
int Pop(LinkStack *S, ElemType *x) {
    if (*S == NULL) return 0;  // 栈空
    StackNode *p = *S;
    *x = p->data;
    *S = p->next;
    free(p);
    return 1;
}
```

### 栈的应用（重要！）

| 应用场景 | 说明 | 示例 |
|----------|------|------|
| **表达式求值** | 中缀转后缀，然后计算 | `3 + 4 × 2` → `3 4 2 × +` |
| **括号匹配** | 检查括号是否成对匹配 | `{[()]}` |
| **函数调用** | 保存返回地址和局部变量 | 递归函数的实现原理 |
| **递归调用** | 递归的底层实现 | 求阶乘、斐波那契 |
| **浏览器前进/后退** | 历史记录管理 | ⬅️ →按钮 |

> 📌 **考研重点**：表达式求值（中缀→后缀）是高频考点！

### 表达式求值详解

**中缀表达式**：我们常用的写法，如 `3 + 4 × 2`

**后缀表达式**（逆波兰式）：运算符在操作数后面
- 优点：无需考虑优先级和括号
- 计算方式：用栈扫描，遇到数字入栈，遇到运算符弹出两个数计算

```
示例：中缀表达式 A + B × C
后缀表达式：A B C × +

计算过程：
1. 扫描到A，入栈 → [A]
2. 扫描到B，入栈 → [A, B]
3. 扫描到C，入栈 → [A, B, C]
4. 扫描到×，弹出B和C，计算B×C，结果入栈 → [A, BC]
5. 扫描到+，弹出A和BC，计算A+BC，结果入栈 → [结果]
```

## 2.2 队列（Queue）
#第2章-栈和队列/队列

### 什么是队列？
队列也是一种**受限的线性表**，只能在一端（队尾）插入，在另一端（队首）删除。

```
📌 简单理解：就像银行排队，先来的先办理
```

**核心特点**：先进先出（**FIFO**：First In First Out）

```
队列示意图：
  入队 → [数据1][数据2][数据3][数据4] → 出队
              ↑                       ↑
            队首(front)              队尾(rear)
```

### 队列的基本操作

| 操作 | 说明 | 时间复杂度 |
|------|------|------------|
| `Enqueue(x)` | 入队，把x加入队尾 | O(1) |
| `Dequeue()` | 出队，弹出队首元素 | O(1) |
| `GetHead()` | 查看队首元素（不删除） | O(1) |
| `IsEmpty()` | 判断队列是否为空 | O(1) |
| `Clear()` | 清空队列 | O(n) |

### 循环队列（重要！）

**为什么需要循环队列？**
- 普通队列用数组实现时， rear 一直增加会导致数组溢出
- 循环队列把数组首尾相连，形成"环"

```
循环队列示意图：
        ┌───────────────┐
        │  ↓ front=2   │
    ┌───┴───┬───┬───┬───┐
    │  c  │ d │ e │ a │ b │
    └───┬───┴───┴───┼───┘
        │           ↑
        └─ rear=4 ──┘
        
数组下标:  0   1   2   3   4
```

**循环队列的实现**：
```c
#define MAXSIZE 100

typedef struct {
    ElemType data[MAXSIZE];
    int front;  // 队首指针
    int rear;   // 队尾指针（指向队尾的下一个位置）
} SqQueue;

// 初始化
void InitQueue(SqQueue *Q) {
    Q->front = Q->rear = 0;
}

// 判断队满：牺牲一个存储单元
int IsFull(SqQueue *Q) {
    return (Q->rear + 1) % MAXSIZE == Q->front;
}

// 判断队空
int IsEmpty(SqQueue *Q) {
    return Q->front == Q->rear;
}

// 入队
int Enqueue(SqQueue *Q, ElemType x) {
    if (IsFull(Q)) return 0;  // 队满
    Q->data[Q->rear] = x;
    Q->rear = (Q->rear + 1) % MAXSIZE;
    return 1;
}

// 出队
int Dequeue(SqQueue *Q, ElemType *x) {
    if (IsEmpty(Q)) return 0;  // 队空
    *x = Q->data[Q->front];
    Q->front = (Q->front + 1) % MAXSIZE;
    return 1;
}
```

> 📌 **考研易错点**：循环队列如何判断队满队空？
> - 常用方法：牺牲一个存储单元，`rear + 1 == front` 表示队满

### 链式队列

```c
typedef struct QueueNode {
    ElemType data;
    struct QueueNode *next;
} QueueNode;

typedef struct {
    QueueNode *front;  // 队首指针（指向头结点）
    QueueNode *rear;   // 队尾指针
} LinkQueue;

// 入队
void Enqueue(LinkQueue *Q, ElemType x) {
    QueueNode *p = (QueueNode *)malloc(sizeof(QueueNode));
    p->data = x;
    p->next = NULL;
    Q->rear->next = p;
    Q->rear = p;
}

// 出队
int Dequeue(LinkQueue *Q, ElemType *x) {
    if (Q->front == Q->rear) return 0;  // 队空
    QueueNode *p = Q->front->next;
    *x = p->data;
    Q->front->next = p->next;
    if (Q->rear == p)  // 删除最后一个节点
        Q->rear = Q->front;
    free(p);
    return 1;
}
```

## 2.3 双端队列（Deque）
#第2章-栈和队列/双端队列

**双端队列**是允许在两端（队首和队尾）同时进行插入和删除操作的队列。

```
双端队列操作：
    ← 前端出/入队 →    ← 后端出/入队 →
    ┌───┬───┬───┬───┬───┬───┐
    │ a │ b │ c │ d │ e │ f │
    └───┴───┴───┴───┴───┴───┘
```

**特殊类型**：
- **输入受限的双端队列**：一端可插入删除，另一端只能删除
- **输出受限的双端队列**：一端可插入删除，另一端只能插入

> 📌 **考研考点**：双端队列常用于设计算法题，考察对限制条件的理解

## 2.4 栈和队列对比
#第2章-栈和队列/对比总结

| 特性 | 栈 | 队列 |
|------|-----|------|
| **操作位置** | 只能在栈顶 | 队尾入，队首出 |
| **原则** | 后进先出(LIFO) | 先进先出(FIFO) |
| **实现方式** | 顺序栈、链式栈 | 循环队列、链式队列 |
| **时间复杂度** | 所有操作O(1) | 所有操作O(1) |
| **典型应用** | 表达式求值、递归、括号匹配 | 层次遍历、BFS、调度 |

1. **【2011统考真题】** 栈和队列的共同点是？
   A. 都是线性结构  
   B. 都是非线性结构  
   C. 都不允许在中间访问  
   D. 都不允许在中间插入  
   > **答案**：A、C

   C. rear == (front + 1) % (m + 1)  
   D. front == 0  
   > **答案**：A  
   > **解析**：循环队列判断队空的标准是front == rear。

3. **【2015统考真题】** 栈的Push和Pop操作序列为Push(a), Push(b), Push(c), Pop(), Pop(), Push(d), Pop(), Pop()，输出序列是？

   C. c b d a  
   D. d c b a

   > **解析**：按照栈的LIFO原则，输出顺序为c, b, d, c。

   B. a c d  
   C. a b c

### 综合应用题

6. **【2016统考真题】** 设计一个算法，判断一个链表是否为回文链表。

**思路**：用栈或队列辅助存储，对比前半部分和后半部分

```c
bool isPalindrome(ListNode *head) {
    if (!head || !head->next) return true;
    
    // 快慢指针找中点
    ListNode *slow = head, *fast = head;
    Stack<int> s;
    
    while (fast && fast->next) {
        s.push(slow->data);
        slow = slow->next;
        fast = fast->next->next;
    }
    if (fast) slow = slow->next;  // 奇数个，跳过中间
    
    while (slow) {
        if (s.top() != slow->data) return false;
        s.pop();
        slow = slow->next;
    }
    return true;
}
```

7. **【2019统考真题】** 用栈实现括号匹配算法。

```c
bool bracketMatch(char *str) {
    Stack<char> s;
    while (*str) {
        if (*str == '(' || *str == '[' || *str == '{')
            s.push(*str);
        else if (*str == ')' || *str == ']' || *str == '}') {
            if (s.empty()) return false;
            char top = s.top();
            s.pop();
            if ((*str == ')' && top != '(') ||
                (*str == ']' && top != '[') ||
                (*str == '}' && top != '{'))
                return false;
        }
        str++;
    }
    return s.empty();
}
```
