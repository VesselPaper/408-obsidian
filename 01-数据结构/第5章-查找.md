# 第5章-查找

## 5.1 顺序查找
#第5章-查找/顺序查找
**顺序查找**是从[[01-数据结构/第1章-线性表|线性表]]的一端开始，逐个比较元素。

**时间复杂度**：O(n)

**优点**：
- 算法简单
- 适用于任何存储结构

**缺点**：
- 查找效率低
- 适用于小规模数据

**实现**：
```c
int SequentialSearch(int a[], int n, int key) {
    for (int i = 0; i < n; i++) {
        if (a[i] == key) {
            return i;
        }
    }
    return -1;
}
```

**优化**：
- 设置哨兵：将待查找的关键字放在数组的末尾，减少比较次数

## 5.2 折半查找
**折半查找**是在有序的[[01-数据结构/第1章-线性表|线性表]]中，每次将查找范围缩小一半。

**时间复杂度**：O(logn)

**优点**：
- 查找效率高
- 平均查找长度小

**缺点**：
- 只适用于有序表
- 只适用于顺序存储结构

**实现**：
```c
int BinarySearch(int a[], int n, int key) {
    int low = 0, high = n-1;
    while (low <= high) {
        int mid = (low + high) / 2;
        if (a[mid] == key) return mid;
        else if (a[mid] > key) high = mid - 1;
        else low = mid + 1;
    }
    return -1;
}
```

**递归实现**：
```c
int BinarySearchRecursive(int a[], int low, int high, int key) {
    if (low > high) return -1;
    int mid = (low + high) / 2;
    if (a[mid] == key) return mid;
    else if (a[mid] > key) return BinarySearchRecursive(a, low, mid-1, key);
    else return BinarySearchRecursive(a, mid+1, high, key);
}
```

## 5.3 分块查找
**分块查找**是将线性表分成若干块，块内无序，块间有序。

**步骤**：
1. 先确定待查找元素所在的块
2. 在块内进行顺序查找

**时间复杂度**：O(√n)

**优点**：
- 结合了顺序查找和折半查找的优点
- 适用于大型线性表

## 5.4 哈希表
**哈希表**是通过哈希函数将键映射到存储位置的数据结构。

**哈希函数**：将键转换为存储位置的函数

**冲突**：不同的键映射到相同的存储位置

**冲突处理**：
- 开放定址法：冲突时寻找下一个空位置
  - 线性探测：顺序查找下一个空位置
  - 二次探测：平方探测
  - 双重哈希：使用两个哈希函数
- 链地址法：冲突时将元素链接在同一位置
- 再哈希法：使用多个哈希函数
- 建立公共溢出区：将冲突元素放入溢出区

**哈希函数的设计**：
- 直接定址法：直接使用键值
- 数字分析法：选择数字的某些位
- 平方取中法：取键值平方的中间几位
- 折叠法：将键值分割后折叠
- 除留余数法：取键值除以质数的余数

**哈希表的查找效率**：
- 平均查找长度：O(1)
- 最坏情况：O(n)（所有元素都冲突）

**实现**：
```c
// 哈希表定义
typedef struct {
    ElemType *elem; // 数据元素存储基址
    int count;      // 当前元素个数
    int sizeindex;  // 哈希表容量索引
} HashTable;
```

## 5.5 树表查找
**二叉排序树查找**：见[[01-数据结构/第3章-树和二叉树|二叉排序树]]

**平衡二叉树查找**：见[[01-数据结构/第3章-树和二叉树|平衡二叉树]]

**B树**：一种多路平衡查找树

**B树的性质**：
- 每个节点最多有m个子节点
- 根节点至少有2个子节点
- 非根节点至少有⌈m/2⌉个子节点
- 所有叶子节点在同一层
- 每个节点的关键字按顺序排列

**B树的查找**：
1. 从根节点开始
2. 在节点中查找关键字
3. 若找到，返回
4. 若没找到，根据关键字大小选择子节点继续查找
5. 若到达叶子节点仍未找到，返回失败

**B+树**：B树的变体

**B+树的特点**：
- 所有关键字都在叶子节点
- 叶子节点形成有序链表
- 非叶子节点只存储关键字和子节点指针

**应用**：
- 数据库索引
- 文件系统

## 5.6 查找算法的比较
| 查找方法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|---------|-----------|-----------|----------|
| 顺序查找 | O(n) | O(1) | 无序或小规模数据 |
| 折半查找 | O(logn) | O(1) | 有序顺序表 |
| 分块查找 | O(√n) | O(1) | 大型线性表 |
| 哈希查找 | O(1) | O(n) | 频繁查找的场景 |
| 二叉排序树 | O(logn) | O(n) | 动态数据 |
| 平衡二叉树 | O(logn) | O(n) | 动态数据，要求平衡 |
| B树/B+树 | O(logn) | O(n) | 大规模数据，磁盘存储 |
