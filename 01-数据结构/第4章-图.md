# 第4章-图

> 图是比树更一般的非线性结构，可以表示任意两个元素之间的关联关系。考研重点章节！

## 4.1 图的基本概念
#第4章-图/图的基本概念

### 什么是图？

```
📌 简单理解：图就像社交网络
- 顶点 = 人
- 边 = 人与人的关系

示例：微信好友关系图
    张三 ── 李四 ── 王五
     │       │
     └───────┘
```

### 图的基本术语

| 术语 | 含义 | 举例 |
|------|------|------|
| **顶点** | 图中的节点 | V={A,B,C,D} |
| **边** | 连接两个顶点的线 | E={(A,B),(B,C)} |
| **有向图** | 边有方向 | A→B |
| **无向图** | 边无方向 | A—B |
| **权** | 边的数值（距离/费用） | A到B距离5km |
| **度** | 顶点连接的边数 | A的度=3 |
| **入度/出度** | 有向图中进入/出发的边数 | A的出度=2 |

### 图的分类

```
无向图：              有向图：
   A                    A → B
  /|\                  ↙  ↓
 B C D                C ← D
 (A的度=3)            (A出度1，入度0)

完全图：
- 无向完全图：n个顶点，n(n-1)/2条边
- 有向完全图：n个顶点，n(n-1)条边
```

### 图的重要性质

```
📌 考研必记！

1. 无向图中：所有顶点的度数之和 = 2 × 边数
   例：5条边，总度数=10

2. 有向图中：所有顶点的入度之和 = 所有顶点的出度之和 = 边数

3. 连通图：任意两个顶点之间有路径
   - 连通分量：无向图的极大连通子图
   
4. 强连通图：有向图中任意两点互相可达

5. 生成树：包含所有顶点的极小连通子图（n-1条边）
```

## 4.2 图的存储结构
#第4章-图/图的存储结构

### 邻接矩阵

```
无向图邻接矩阵示例：

   A B C D
A [0 1 1 0]
B [1 0 0 1]
C [1 0 0 1]
D [0 1 1 0]

特点：
- 对称矩阵（无向图）
- 适合稠密图
- 空间O(V²)
```

```c
#define MAXV 100

typedef struct {
    int arcs[MAXV][MAXV];  // 邻接矩阵
    int vexnum, arcnum;   // 顶点数、边数
} MGraph;
```

### 邻接表（常用！）

```
邻接表示例（无向图）：

A: B → C →
B: A → D →
C: A → D →
D: B → C →

特点：
- 适合稀疏图
- 空间O(V+E)
- 无向图每条边存两次
```

```c
typedef struct ArcNode {
    int adjvex;              // 邻接点下标
    struct ArcNode *nextarc; // 下一条边
    int weight;              // 权值
} ArcNode;

typedef struct VNode {
    ArcNode *firstarc;       // 第一条边
} VNode, AdjList[MAXV];
```

### 存储结构对比

| 结构 | 适用场景 | 空间复杂度 | 特点 |
|------|----------|------------|------|
| 邻接矩阵 | 稠密图 | O(V²) | 访问快、适合完全图 |
| 邻接表 | 稀疏图 | O(V+E) | 更常用，省空间 |

## 4.3 图的遍历（重点！）
#第4章-图/图的遍历

### 深度优先搜索（DFS）

```
📌 类似"走迷宫"，一条路走到黑，再回溯

DFS示例（从A开始）：
A → B → D → 回溯 → C → ...

遍历序列（不唯一）：
A B D C 或 A C D B
```

```c
void DFS(Graph G, int v) {
    visit(v);
    visited[v] = TRUE;
    for (每个邻接点 w) {
        if (!visited[w]) DFS(G, w);
    }
}
```

### 广度优先搜索（BFS）

```
📌 类似"水面波纹"，一层一层扩散

BFS示例（从A开始）：
第一层：A
第二层：B,C
第三层：D
...

遍历序列：A B C D
```

```c
void BFS(Graph G, int v) {
    InitQueue(Q);
    visited[v] = TRUE;
    EnQueue(Q, v);
    while (!Empty(Q)) {
        DeQueue(Q, u);
        visit(u);
        for (每个邻接点 w) {
            if (!visited[w]) {
                visited[w] = TRUE;
                EnQueue(Q, w);
            }
        }
    }
}
```

> 📌 **考研考点**：DFS用栈，BFS用队列，时间复杂度都是O(V+E)

## 4.4 最小生成树（重要！）
#第4章-图/最小生成树

### 什么是生成树？

生成树包含图的所有顶点，用**n-1条边**连接：

```
原图（4顶点5条边）：    生成树（4顶点3条边）：
    A                    A
   /|\                  /|\
  B C D                B C D
   \                   /
    ──                 ──

生成树特点：
- 连通
- 无环
- 边数 = 顶点数 - 1
```

### 最小生成树（MST）

**最小生成树**是边权之和最小的生成树：

```
示例：
    2
  A───B
  │╲  │
 6  ╲ 3
  │   ╲
  C────D
     4

最小生成树边：A-B(2), B-D(3), A-C(6) = 11
```

### Prim算法（适合稠密图）

```
算法思想：从一个顶点开始，每次选择离生成树最近的顶点

步骤：
1. 从顶点A开始
2. 选择到A最近的边（A-B=2）
3. 选择到{A,B}最近的边（B-D=3）
4. 选择到{A,B,D}最近的边（A-C=6）
5. 完成！边：AB, BD, AC
```

```c
void Prim(Graph G, int v) {
    int lowcost[MAXV];
    int adjvex[MAXV];
    
    // 初始化
    for (i=0; i<G.vexnum; i++) {
        lowcost[i] = G.arcs[v][i];
        adjvex[i] = v;
    }
    
    // 选择n-1条边
    for (k=1; k<G.vexnum; k++) {
        // 找最小权边
        min = INF;
        for (i=0; i<G.vexnum; i++) {
            if (lowcost[i] < min && lowcost[i] != 0) {
                min = lowcost[i];
                minvex = i;
            }
        }
        printf("%d-%d\n", adjvex[minvex], minvex);
        lowcost[minvex] = 0;  // 加入生成树
        
        // 更新
        for (i=0; i<G.vexnum; i++) {
            if (G.arcs[minvex][i] < lowcost[i]) {
                lowcost[i] = G.arcs[minvex][i];
                adjvex[i] = minvex;
            }
        }
    }
}
```

### Kruskal算法（适合稀疏图）

```
算法思想：按边权排序，依次选择不形成环的边

步骤：
1. 按边权排序：AB(2), BD(3), AC(6), AD(5?)...
2. 选择AB（不形成环）✓
3. 选择BD（不形成环）✓
4. 选择AC（不形成环）✓
5. 完成！
```

```c
// 并查集实现Kruskal
void Kruskal(Graph G) {
    sort edges by weight;
    init Union-Find;
    
    for (每条边 e) {
        if (e.u 和 e.v 不在同一集合) {
            union(e.u, e.v);
            printf("%d-%d\n", e.u, e.v);
        }
    }
}
```

> 📌 **对比**：
> - Prim：O(V²)，适合稠密图
> - Kruskal：O(ElogE)，适合稀疏图

## 4.5 最短路径（核心重点！）
#第4章-图/最短路径

### Dijkstra算法（单源最短路径）

```
📌 核心思想：贪心，每次选择最近的顶点

示例图（从A出发）：
    2       4
  A───B───C───D
  │   ╲   │
 1  ╲  9  6
  │   ╲   │
  └────E───┘
       3

Dijkstra步骤：
1. dist[A]=0, 其他=∞
2. 选A：更新 dist[B]=2, dist[E]=1
3. 选E(dist=1)：更新 dist[B]=2(不变)
4. 选B(dist=2)：更新 dist[C]=2+4=6
5. 选C(dist=6)：更新 dist[D]=6+6=12
6. 最终：A→B=2, A→E=1, A→C=6, A→D=12
```

```c
void Dijkstra(Graph G, int v) {
    int dist[MAXV], s[MAXV];
    
    // 初始化
    for (i=0; i<G.vexnum; i++) {
        dist[i] = G.arcs[v][i];
        s[i] = 0;
    }
    s[v] = 1;
    
    // 找n-1条最短路径
    for (i=1; i<G.vexnum; i++) {
        min = INF;
        // 选最近的顶点
        for (j=0; j<G.vexnum; j++) {
            if (!s[j] && dist[j] < min) {
                min = dist[j];
                u = j;
            }
        }
        s[u] = 1;
        
        // 更新距离
        for (j=0; j<G.vexnum; j++) {
            if (!s[j] && dist[u] + G.arcs[u][j] < dist[j]) {
                dist[j] = dist[u] + G.arcs[u][j];
            }
        }
    }
}
```

> 📌 **注意**：Dijkstra不能处理负权边！

### Floyd算法（多源最短路径）

```
算法思想：动态规划，尝试每个顶点作为中间点

核心公式：
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

时间复杂度：O(V³)
适合：需要所有顶点对最短路径时
```

```c
void Floyd(Graph G) {
    for (i=0; i<G.vexnum; i++)
        for (j=0; j<G.vexnum; j++)
            dist[i][j] = G.arcs[i][j];
    
    for (k=0; k<G.vexnum; k++)
        for (i=0; i<G.vexnum; i++)
            for (j=0; j<G.vexnum; j++)
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
}
```

### 最短路径算法对比

| 算法 | 作用 | 时间复杂度 | 特点 |
|------|------|------------|------|
| Dijkstra | 单源最短 | O(V²) | 不能负权 |
| Floyd | 多源最短 | O(V³) | 可以负权 |
| Bellman-Ford | 单源最短 | O(VE) | 能检测负环 |
| SPFA | 单源最短 | O(VE) | Bellman优化 |

## 4.6 拓扑排序（重要！）
#第4章-图/拓扑排序

### 什么是拓扑排序？

```
📌 简单理解：排序后保证"先学的课程在前"

示例：课程依赖关系
  数据结构 → 数据库
  高等数学 → 线性代数
  数据结构 → 算法
  
拓扑序列：高等数学 → 数据结构 → 线性代数 → 数据库 → 算法
        （或：高等数学 → 线性代数 → 数据结构 → 数据库 → 算法）
```

### 拓扑排序算法

```c
void TopologicalSort(Graph G) {
    int indegree[MAXV];
    Queue Q;
    
    // 1. 计算所有顶点入度
    for (i=0; i<G.vexnum; i++)
        indegree[i] = 0;
    for (i=0; i<G.vexnum; i++)
        for (p=G.vertices[i].firstarc; p; p=p->nextarc)
            indegree[p->adjvex]++;
    
    // 2. 入度为0的入队
    for (i=0; i<G.vexnum; i++)
        if (indegree[i] == 0) EnQueue(Q, i);
    
    // 3. 依次出队输出
    while (!Empty(Q)) {
        DeQueue(Q, i);
        printf("%d ", i);
        for (p=G.vertices[i].firstarc; p; p=p->nextarc) {
            indegree[p->adjvex]--;
            if (indegree[p->adjvex] == 0) EnQueue(Q, p->adjvex);
        }
    }
}
```

> 📌 **考研重点**：拓扑排序可以判断是否有环！
> - 如果排序后顶点数量 < 总顶点数，说明有环

## 4.7 关键路径（重要！）
#第4章-图/关键路径

### 什么是关键路径？

关键路径是**项目中最长的路径**，决定项目最短完成时间：

```
项目网络图：
    A(开始) → B → C → D(结束)
    │         │    │
    └─────────┘    │
         E─────────┘

关键路径：A→B→C→D（所有活动都不能延迟）
关键活动：关键路径上的活动
```

### 关键路径计算

```c
// 计算关键路径步骤：
1. 拓扑排序
2. 求每个事件的最早发生时间 ve[]
3. 求每个事件的最迟发生时间 vl[]
4. 求每个活动的最早/最迟开始时间
5. 活动最早=最迟即为关键活动
```

> 📌 **易错点**：关键路径可能不只一条！
