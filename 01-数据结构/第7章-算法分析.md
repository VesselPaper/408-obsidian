# 第7章-算法分析

## 7.1 算法的基本概念

#第7章-算法分析/算法的基本概念
**算法**是解决问题的步骤集合，具有以下特性：
- 有穷性：算法必须在有限步骤内结束
- 确定性：每一步都有明确的定义
- 可行性：每一步都可以通过基本操作实现
- 输入：算法有零个或多个输入
- 输出：算法有一个或多个输出

**算法与程序的区别**：
- 算法是解决问题的步骤，程序是算法的实现
- 算法必须有穷，程序可以无限循环
- 算法更抽象，程序更具体

## 7.2 时间复杂度

#第7章-算法分析/时间复杂度
**时间复杂度**是算法执行时间随问题规模增长的变化趋势，用于分析[[01-数据结构/第6章-排序|排序]]、[[01-数据结构/第5章-查找|查找]]等算法的效率。

**时间复杂度的分析方法**：
1. 找出基本操作
2. 计算基本操作的执行次数
3. 取最高次项，忽略常数和低次项

**常见复杂度**：
- O(1)：常数时间
- O(logn)：对数时间
- O(n)：线性时间
- O(nlogn)：线性对数时间
- O(n²)：平方时间
- O(n³)：立方时间
- O(2^n)：指数时间
- O(n!)：阶乘时间

**复杂度比较**：
O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2^n) < O(n!)

**最好、平均、最坏情况**：
- 最好情况：最有利的输入
- 平均情况：所有可能输入的期望
- 最坏情况：最不利的输入

## 7.3 空间复杂度

#第7章-算法分析/空间复杂度
**空间复杂度**是算法所需存储空间随问题规模增长的变化趋势。

**空间复杂度的分析**：
- 算法本身的存储空间
- 输入数据的存储空间
- 辅助变量的存储空间

**常见空间复杂度**：
- O(1)：常数空间
- O(logn)：对数空间
- O(n)：线性空间
- O(n²)：平方空间

## 7.4 算法设计策略

#第7章-算法分析/算法设计策略
**分治法**：将问题分解为子问题，递归求解

**分治法步骤**：
1. 分解：将问题分解为子问题
2. 求解：递归求解子问题
3. 合并：合并子问题的解

**应用**：
- 快速排序
- 归并排序
- 二分查找
- 大整数乘法

**动态规划**：利用子问题的解构建原问题的解

**动态规划步骤**：
1. 定义状态
2. 确定状态转移方程
3. 初始化边界条件
4. 计算状态值
5. 构造解

**应用**：
- 斐波那契数列
- 最长公共子序列
- 背包问题
- 最短路径

**贪心算法**：每一步选择当前最优解

**贪心算法的要素**：
- 贪心选择性质：局部最优解能导致全局最优解
- 最优子结构：问题的最优解包含子问题的最优解

**应用**：
- 活动选择问题
- 霍夫曼编码
- 最小生成树（Prim算法、Kruskal算法）
- 单源最短路径（Dijkstra算法）

**回溯法**：尝试所有可能的解，回溯排除无效解

**回溯法步骤**：
1. 定义问题的解空间
2. 确定搜索策略
3. 搜索解空间
4. 剪枝：排除无效解

**应用**：
- 八皇后问题
- 迷宫问题
- 子集和问题
- 图的着色问题

**分支限界法**：广度优先搜索，使用剪枝策略

**分支限界法的类型**：
- 队列式分支限界法：使用队列
- 优先队列式分支限界法：使用优先队列

**应用**：
- 旅行商问题
- 0-1背包问题
- 布线问题

## 7.5 算法的正确性

#第7章-算法分析/算法的正确性
**算法的正确性**：算法能够正确解决问题

**正确性证明**：
- 归纳法
- 循环不变式
- 不变量

**算法的健壮性**：算法能够处理异常情况

**算法的可读性**：算法易于理解和维护

## 7.6 算法的优化

#第7章-算法分析/算法的优化
**时间优化**：
- 减少基本操作的次数
- 选择更高效的算法
- 使用空间换时间

**空间优化**：
- 减少辅助空间的使用
- 选择更节省空间的算法
- 使用时间换空间

**代码优化**：
- 循环优化
- 递归优化
- 数据结构优化
