# 第1章-线性表

> 本章是数据结构的基础，学好线性表对理解栈、队列、树、图等复杂结构至关重要。

## 1.1 线性表的定义
#第1章-线性表/线性表的定义

**线性表**是最简单、最基本的一种数据结构一一对应关系的数据元素的有序序列。

```
📌 简单理解：就像排队买票一样，一条线上的元素，第一个之前没有"前驱"，最后一个之后没有"后继"
```

**形式化定义**：线性表是n(n≥0)个数据元素的有限序列，记作(a₁, a₂, ..., aₙ)

**核心特征**：
- **有序性**：元素之间有顺序关系
- **唯一前驱/后继**：除第一个元素外，每个元素都有且仅有一个前驱；除最后一个元素外，每个元素都有且仅有一个后继

```
图示：
a₁ → a₂ → a₃ → ... → aₙ
 ↑       ↑          ↑
前驱   当前位置    后继
```

## 1.2 线性表的基本操作
#第1章-线性表/基本操作

| 操作                     | 说明         | 复杂度  |
| ---------------------- | ---------- | ---- |
| `InitList(L)`          | 初始化一个空表    | O(1) |
| `Length(L)`            | 返回表长       | O(1) |
| `GetElem(L, i, &e)`    | 获取第i个元素    | O(1) |
| `LocateElem(L, e)`     | 查找元素e的位置   | O(n) |
| `ListInsert(L, i, e)`  | 在第i位置插入元素e | O(n) |
| `ListDelete(L, i, &e)` | 删除第i位置的元素  | O(n) |
| `PrintList(L)`         | 遍历输出所有元素   | O(n) |
| `DestroyList(L)`       | 销毁表，释放内存   | O(n) |

## 1.3 顺序表
#第1章-线性表/顺序表

**顺序表**就是用**数组**来存储线性表，元素在内存中连续存放。

```
内存示意图：
┌───┬───┬───┬───┬───┬───┐
│ a₁│ a₂│ a₃│ a₄│ a₅│ ...│  连续地址
└───┴───┴───┴───┴───┴───┘
 ↑
 data[0]
```

**存储结构定义**：
```c
#define MAXSIZE 100  // 最大容量

typedef struct {
    ElemType data[MAXSIZE];  // 存放数据的数组
    int length;              // 当前长度
} SqList;
```

**特点**：
- ✅ **优点**：随机访问快（O(1)），存储密度高
- ❌ **缺点**：插入删除需要移动元素（O(n)），容量固定

**插入操作示意**：
```
插入前：[a₁][a₂][a₃][a₄][   ]
              ↑ 在a₂后插入x

插入后：[a₁][a₂][ x ][a₃][a₄][   ]
              ↑ 需要把a₃.a₄后移
```

## 1.4 链表
#第1章-线性表/链表

**链表**用**指针**将分散的存储单元链接起来，不需要连续内存。

### 1.4.1 单链表
```c
typedef struct LNode {
    ElemType data;           // 数据域：存储数据
    struct LNode *next;      // 指针域：指向下一个节点
} LNode, *LinkList;
```

```
内存示意图（单链表）：
┌───┬───┐    ┌───┬───┐    ┌───┬───┐    ┌─────┐
│ a₁│next│───▶│ a₂│next│───▶│ a₃│next│───▶│NULL │
└───┴───┘    └───┴───┘    └───┴───┘    └─────┘
  节点1        节点2        节点3        尾节点
```

**头结点**：带头结点的链表操作更统一，头结点不存储数据

### 1.4.2 双链表
```c
typedef struct DNode {
    ElemType data;           // 数据域
    struct DNode *prior;     // 前驱指针
    struct DNode *next;      // 后继指针
} DNode, *DLinkList;
```

```
双链表示意图：
┌────┬───┬───┐    ┌────┬───┬───┐
│NULL│ a₁│next│◀───│prior│ a₂│next│◀── ...
└────┴───┴───┘    └────┴───┴───┘
   ↑                              ↓
   └──────────────────────────────┘
```

### 1.4.3 循环链表
- **循环单链表**：尾节点next指向头节点
- **循环双链表**：头节点prior指向尾节点，尾节点next指向头节点

**特点**：
- ✅ **优点**：插入删除不需要移动元素，内存灵活
- ❌ **缺点**：不能随机访问，存储密度低（需要存指针）

## 1.5 顺序表 vs 链表怎么选？
#第1章-线性表/顺序表与链表的比较

| 对比项 | 顺序表 | 链表 |
|--------|--------|------|
| **存储方式** | 连续内存 | 分散内存，通过指针连接 |
| **访问方式** | 随机访问 O(1) | 顺序访问 O(n) |
| **插入删除** | 需要移动元素 O(n) | 只需修改指针 O(1) |
| **存储密度** | 高（无需额外空间） | 低（需要存指针） |
| **内存分配** | 静态/动态数组 | 动态申请节点 |
| **适用场景** | 频繁查找、少改删 | 频繁改删、少查找 |

```
📌 考研选择题高频考点：如何选择？
- 经常查找 → 顺序表
- 经常插入删除 → 链表
- 内存紧张 → 顺序表（存储密度高）
- 数据量不确定 → 链表（灵活扩展）
```

## 习题1（考研真题精选）

### 选择题

1. **【2011统考真题】** 某线性表最常用的操作是在尾元素之后插入一个元素和删除第一个元素，则利用以下哪种数据结构效率最高？
   A. 单链表  
   B. 单循环链表  
   C. 带尾指针的单循环链表  
   D. 双链表  
   > **答案**：C  
   > **解析**：带尾指针的单循环链表可以在O(1)时间内完成尾插和头删。

2. **【2014统考真题】** 顺序表的插入算法中，当数组空间不足时，通常将数组扩大一倍，而扩大一倍时插入元素的平均时间复杂度为？
   A. O(1)  B. O(n)  C. O(n²)  D. O(nlogn)  
   > **答案**：B  
   > **解析**：每次扩容需要复制n个元素到新数组，共n次插入，平均每次O(n)。

3. **【2017统考真题】** 某顺序表采用顺序存储，现要将其改为链表，则以下说法正确的是？
   A. 顺序表优缺点：插入删除方便，查找不方便  
   B. 链表优缺点：插入删除方便，查找不方便  
   C. 顺序表优缺点：查找方便，插入删除不方便  
   D. 链表优缺点：查找方便，插入删除不方便  
   > **答案**：C

### 应用题

4. **【2009统考真题】** 已知顺序表L=(a₁, a₂, a₃, ..., aₙ)，试写出将顺序表反转的算法，要求空间复杂度为O(1)。

**参考解答**：
```c
void Reverse(SqList *L) {
    ElemType temp;
    for (int i = 0; i < L->length/2; i++) {
        temp = L->data[i];
        L->data[i] = L->data[L->length - 1 - i];
        L->data[L->length - 1 - i] = temp;
    }
}
```

5. **【2016统考真题】** 已知单链表L，设计一个算法删除L中所有值为x的节点。

**参考解答**：
```c
void DeleteX(LinkList L, ElemType x) {
    LNode *p = L->next, *pre = L;
    while (p) {
        if (p->data == x) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}
```

> **本章小结**
> 1. 线性表是最基础的结构，有顺序存储和链式存储两种方式
> 2. 顺序表随机访问快，链表插入删除快
> 3. 选择依据：查多改少用顺序表，改多查少用链表
